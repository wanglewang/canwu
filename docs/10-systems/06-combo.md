# 连 S 叠倍率

> 全站唯一一个「打得越好，后面越值钱」的机制。它取代了旧版「三连 S 直接晋级」，也是「段位值不值得打」这个问题的答案。

---

## 1. 一句话

同一门功法**连续拿 S**，第 k 连给 `round(34 × 1.5^(k-1))` 点熟练度，最多 10 层；任何非 S 都会清零。

## 2. 曲线表

| 连 | 熟练度 | 累计 |
| --- | --- | --- |
| 1 | 34 | 34 |
| 2 | 51 | 85 |
| 3 | 77 | 162 |
| 4 | 115 | 277 |
| 5 | 172 | 449 |
| 6 | 258 | 707 |
| 7 | 387 | 1094 |
| 8 | 581 | 1675 |
| 9 | 871 | 2546 |
| 10 | 1307 | **3853** |
| 11+ | 1307（锁死） | 每局 +1307 |

一轮十连 = **3853 点**，比十局单 S（340 点）多 **11.3 倍**。

`COMBO_STEP = 1.5`、`COMBO_MAX = 10`、`COMBO_CAP_GAIN = 1307`。

## 3. 三条边界

### 3.1 每局独立取整

`round(34 × 1.5^(k-1))` **每次从 34 起算一次取整**，不是拿上一局的整数继续乘。

两种算法会分叉：`34 → 51 → 76.5`。逐局取整给 77；连乘整数给 `round(51 × 1.5) = round(76.5) = 77`——这一层恰好一样。但到第 4 层：`round(77 × 1.5) = 116`，而 `round(34 × 3.375) = 115`。**差 1 点**。玩家拿计算器复算 `34 × 1.5^3` 会得到 114.75 → 115，所以取 115。

这条由 `tests/rank.test.js` 与 `simulate.js` 双重守着（含「第 4 连不累进相乘」断言）。

### 3.2 只有当前关的 S 才叠层

回关局：

- **不叠层**（不涨），
- **不砍已有层数**（原样保留），
- **不砍连击收益**（本局给的还是折减后的基础值）。

回当前关打一局 S，接着从 `层数+1` 算。这是「连 S 与回关完全解耦」的具体含义——两套机制不串联取整。

### 3.3 什么会断连

| 事件 | 断连？ | 备注 |
| --- | --- | --- |
| C / B / A | **是** | 连 S 的语义就是「连续」 |
| 失败 F | **是** | 不分段位 |
| 主动结束 | **是** | 靠 `breakCombo()`，页面置 `aborting` |
| 局中返回 / 切页离开 | **是** | `closeAbandonedRound()` 统一结账（2026-11 补） |
| 回关 S | 否 | 不涨也不清 |
| 打到 99999 封顶 | 否 | 层数照常叠，只是熟练度 +0 |
| 换门 | 否（本门层数保留） | 层数**按功法**分别记（`state.sCombo[skillId]`） |
| 突破局「气机一乱」 | 否 | 突破不是参悟，不断连 |

**任何「没打完就走」都必须显式断连**，否则「预感拿不到 S 就中途退出」能永久保连——这是这套机制唯一的漏洞，用 `breakCombo()` 堵住。

2026-11 之前只堵了「结束」那一半：左上角返回与切页都是静默丢盘、不断连，于是最便宜的保连法变成了**不动那个会弹窗的按钮**。
现在三条出口共用 `closeAbandonedRound()`，断连与记钟一起结（见 `30-ui/06-page-skills-practice.md` §5.3）。

## 4. 为什么取代「三连 S 晋级」

旧机制：连续三次 S 直接补额到下一段门槛。

**问题**：补额不看关卡，而回关 S 的概率远高于当前关。于是「只刷第 1 关」能反超「逐关进」——奖励落在了「退到最容易的那一关」上。

模拟抓到这个问题（`npm run sim` 的预算实验）之后，整条机制退役，换成两个闸：

1. **连 S 只在当前关叠**（本机制）；
2. **回关按「本关 ÷ 当前关 × 段基数比」折减**（见 `07-difficulty.md` §5）。

现在两种刷法的实测差距：逐关进 7290 / 只刷本段第 1 关 598。

## 5. 界面表达

| 位置 | 表达 |
| --- | --- |
| 准备页 | 十格小圆点（当前层数点亮）+ 一行「下一局 S 值 258 点」 |
| 局内 HUD | 当前层数（不显示完整表） |
| 结算 | 层数与算式：`34 × 1.5^5 → 258` |
| 说明页 | 完整曲线表 |
| 结束确认 | 明写「连 S 归零」 |

**结束确认里必须写「连 S 归零」**——不然玩家会以为只是放弃这一局的熟练度。实测中这条提示确实让人犹豫（见待验）。

## 6. 数值推导

**为什么底数是 1.5**：十连要形成「值得追」的曲线。1.3 太缓（十连 34→约 350），1.7 太陡（十连 34→约 2300 点，一轮就跨两个段位）。1.5 下十连 3853 点，约等于入门到小成的一半——**一轮好状态能推半段**，这个量级既让人想追，又不至于一次爆段。

**为什么封顶 10 层**：不封顶的话，50 连是 `34 × 1.5^49 ≈ 1.4 万亿`，段位表会被彻底击穿。10 层封顶后单局上限 1307，全程不断 S 毕业 84 局——这个数成了「理论最少局数」，可验证。

**为什么第 11 连锁死而不是衰减**：衰减会让高手在「该不该继续」上纠结；锁死只说一句「到顶了，继续打还是这个数」。

**为什么按功法分别记**：连 S 是「这一门手熟」的表达。若全站共用一条链，练十五门就永远别想叠层；而按功法记，玩家在每门上都可能有一轮好状态。

## 7. 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 三连 S 补额晋级（旧版） | 见第 4 节。会让「刷简单」最优 |
| 连击也乘评级系数 | 会与 `GRADE_FACTOR` 重复计一次，且数值不可复算 |
| 全站共用一条连击链 | 与「分门练习」冲突 |
| 层数有上限但收益继续涨 | 数值上等价于不封顶 |
| 回关也叠层 | 与「回关折减」双重打折，玩家算不清；且会激励刷第 1 关 |
| 断连给「保底保留 1 层」 | 断了就是断了。保底会让「故意断一次」变成策略 |

## 待验

- 第 10 连 1307 点跌回第 1 连 34 点（跌 97%）的挫败感是否劝退。目前只在说明页写清，没有「保一层」的缓冲。
- 结束确认写「连 S 归零」，会不会让人宁可硬着头皮打完拿 C（等于用 10 点换一次断连的确认）。这在真机上需要观察。
- 结算里 `34 × 1.5^9 → 1307` 这行算式在窄卡上是否换行。
