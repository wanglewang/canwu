# 人物属性：四项，各有一件正事

> 旧的四项属性（体魄 / 原属性名 / 悟性 / 身法）全都只进战力。结果是「练哪门都一样」——玩家问「练功有什么用」，答不上来。
>
> 现在每项都有一个**独立出口**，其中三项不经过战力。

---

## 1. 一句话

体魄撑战力，真元拓气海，悟性省灵力，身法稳切磋——四项里只有一项只服务战力。

## 2. 四项表

| 属性 | key | 战力权重 | 出口 | 写法（人物页第三行） |
| --- | --- | --- | --- | --- |
| **体魄** | `ti` | ×1.0 | 只进战力 | 战力根基 |
| **真元** | `ling` | ×1.2 | 每点 +2 灵力上限 | 每点 +2 灵力上限 |
| **悟性** | `wu` | ×0.8 | 参悟耗气按 `min(1.6, 1 + 悟性/200)` 除 | 参悟省灵力 |
| **身法** | `shen` | ×1.0 | 切磋波动下限 `min(0.10, 身法/300)` | 切磋波动更稳 |

`world.attributes[].role` 是这份说明的真源，人物页直接显示在数值下面——不另写一份解释文案。

## 3. 属性怎么算

```js
// computeAttributes
attrs[key] = baseAttributes[key]
           + Σ( 功法.bonus[key] × 段位系数 × 品阶系数 )
```

| 段位 | 系数 | | 品阶 | 系数 |
| --- | --- | --- | --- | --- |
| 未入门 | ×0 | | 黄 | ×1.00 |
| 入门 | ×1 | | 玄 | ×1.30 |
| 小成 | ×1.8 | | 地 | ×1.70 |
| 大成 | ×2.8 | | 天 | ×2.20 |
| 圆满 | ×4 | | | |
| 大圆满 | ×5 | | | |

开局基础：体魄 12 / 真元 12 / 悟性 10 / 身法 11。

战力基础 = `12×1.0 + 12×1.2 + 10×0.8 + 11×1.0 = 45.4`，取整 **45**（炼气加成 0）。

**注意：属性加成不受境界衰减。** 境界只乘在战力总数上（`× (1 + 境界加成 + 功法特效)`），不去压属性本身。旧版曾让高境界「压」低阶功法的属性，被废弃——那会让玩家觉得「练了反而退步」。

## 4. 四个出口的具体换算

### 4.1 真元 → 气海

每点 +2。真元 12 时给 24 点上限（炼气 150 + 24 = 174）。

真元是主属性（权重 1.2，与体魄并列最高），所以「练真元类功法」同时抬战力与气海——这是唯一一项双出口的属性，因为「气海」这个系统需要一个能被玩家主动加大的旋钮。

### 4.2 悟性 → 省灵力

```
耗气 ÷ min(1.6, 1 + 悟性/200)
```

| 悟性 | 系数 | 困难档实价（剑法，基数 17） |
| --- | --- | --- |
| 10（开局） | ×1.05 | 14 |
| 50 | ×1.25 | 12 |
| 120 | ×1.60（封顶） | 9 |

封顶 1.6 是刻意的：不给上限的话，堆悟性会把耗气压到接近 1 点，整个「灵力」系统失效。

### 4.3 身法 → 切磋波动下限

```
波动下限 = min(0.10, 身法 / 300)
```

| 身法 | 下限 | 含义 |
| --- | --- | --- |
| 11（开局） | 3.7% | 最差打出 88.7% 战力 |
| 30 | 10%（封顶） | 最差打出 95% 战力 |

它与 `variance` 特效（踏云 5%、凝露 6%、逐数 4%）走同一个出口，在 `rollBattle` 里相加，合计仍封顶 **98%**（`Math.min(0.98, 0.85 + reach)`）。

> **已知不一致（待拍板）**：代码注释写「每 30 点 +1%，封顶 +10%」，但实现是 `身法/300`，即**每 3 点 +1%、30 点就封顶**。两者差 10 倍。本篇按实现写（这是玩家实际感受到的），并把它列进 `50-balance/04-open-issues.md`。要么改注释，要么把 `1/300` 改成 `1/3000`——前者成本低，后者会让身法几乎无感（11 点只给 0.37%）。

### 4.4 体魄 → 只进战力

没有独立出口。这是刻意的：四项里必须有一项是「纯数值」，否则「堆战力」这件事就没有最直接的抓手。

## 5. 为什么不能都进战力

| 问题 | 表现 |
| --- | --- |
| 练哪门都一样 | 十九门功法只是十九个战力数字，玩家只会挑「加成最高」的那门 |
| 「练功有什么用」答不上来 | 战力只影响切磋与突破门槛，而切磋是可选内容——不切磋的玩家感觉不到任何作用 |
| 无法支撑「灵力经济」 | 气海、省气都需要旋钮；只靠境界的话，玩家在两次破境之间对「能练几局」毫无控制力 |

反过来，**四项都有独立出口也有代价**：玩家要理解四个系统。这个代价用「人物页第三行一句话」来支付——不解释公式，只说这一项管什么。

## 6. 界面

人物页属性格四项：

```
体魄   12        真元   12
战力根基         每点 +2 灵力上限

悟性   10        身法   11
参悟省灵力       切磋波动更稳
```

第三行（`.imm-attr__role`）是后加的，`margin-top: var(--sp-1)`、`--fs-caption`、`--c-imm-text-3`。

## 7. 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 四项只进战力（旧版） | 见第 5 节 |
| 属性也受境界衰减 | 玩家会觉得「练了反而退步」 |
| 悟性不封顶 | 耗气会被压到 1 点，灵力系统失效 |
| 身法直接加减伤害 | 会让切磋变成纯数值比较，波动失去意义 |
| 真元只进气海不进战力 | 主属性不参与战力，等于「练它不涨战力」，与「战力是主线」冲突 |
| 给体魄加一个独立出口（如减伤） | 切磋是镜像对战、无实时战斗，没有「减伤」的落点 |

## 8. 待确认的一处口径

「身法 30 点封顶 10%」意味着：**入场即接近封顶**（开局 11 点已 3.7%，练两门身法就到 10%）。这让「身法」这项属性在中后期几乎没有继续堆的价值。

如果原始设计意图是「每 30 点 +1%、需 300 点才满」，那么身法才是长线属性，但开局只给 0.37%，几乎无感。

两个方案各有代价，目前代码取的是前者（短平快），注释写的是后者。**这一条需要设计者拍板**，本篇不做单方面修改。
