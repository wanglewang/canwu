# 双货币体系：灵力是油，灵石是钱

> 两种货币不是「两种钱」，是**两种性质完全不同的资源**。灵力是会耗尽的燃料，灵石是能存住的通货。两者之间**只有一道单向的闸**：灵石能买灵力，灵力买不回灵石。

---

## 1. 一句话

**灵力管「今天能练几局」，灵石管「能换到什么」。**

- 灵力从**时间**来（闭关、份例）或**用灵石买**，只往**运功**去（参悟、切磋、秘境）。
- 灵石从**对战**来（切磋、秘境），往**购置**去（功法、破境、换灵力）。

两条线只在兑换那一处交叉，而且是单向的：**钱能买油，油换不成钱。** 玩家手上的选择因此有两层——这一池灵力是拿去练功还是拿去挣盘缠；库里那几枚灵石是留着买功法，还是现在换成油把进度推过去。

## 2. 两张表

### 灵力（油）

| 项 | 内容 |
| --- | --- |
| 来源 ① | 闭关：0.5 点/分钟，一次最多算 8 小时（产能 240 点），可随时「打坐」当场收 |
| 来源 ② | 每日份例：当日参悟满 3 次，领灵力 +60（灵石 0） |
| 来源 ③ | 灵石兑换：1 枚 = 100 点，主页点「灵石」那一格（见第 3 节） |
| 消耗 ① | 参悟：每局 6–27 点（见下表），开局即扣，走火与收功都不退 |
| 消耗 ② | 切磋：每场运功 5 点（养息式最多抵 3 点，实扣 2–5），胜负都扣，不够直接拒绝开打 |
| 消耗 ③ | 秘境：每场运功 5 点，同上（与切磋共用同一套三式） |
| 上限 | **有**。气海 =（境界基数 + 真元×2）×（1 + 心法扩池 ≤30%）；炼气 174 起 |
| 溢出 | 满则不再生。闭关坐出来的超出上限部分**当场散掉**，回执写明「气海已满，散去 N 点」 |
| 可交易性 | 单向。灵石能换成它，它换不成灵石，也不能被赠送 |

| 项 | 内容 |
| --- | --- |
| 来源 ① | 切磋：7 位对手 12 / 18 / 26 / 36 / 50 / 70 / 120 |
| 来源 ② | 秘境：3 处 8 / 16 / 30 |
| 来源 ③ | 首胜（切磋）/ 首过（秘境）另给 **8** 枚，一次性 |
| 衰减 | 当日第 n 场：`0.85^(n-1)`。第 1 场全额，第 5 场 52%，第 10 场 23%，第 15 场约 10% |
| 消耗 ① | 藏经阁功法：12 门，16–70 枚（见下表） |

| 可交易性 | 无（只有战力码可分享，不含灵石） |

藏经阁 12 门合计 **363** 枚；三次破境合计 **420** 枚。全盘一次性灵石收入约 **466** 枚（切磋 332 + 秘境 54 + 首胜首过 80），**不足以买齐并破境**——缺口必须靠重复切磋补，这就是衰减存在的意义。

> 兑灵力是第三条支出，天然与「买功法」抢同一笔钱。按 1:100 的价，一枚灵石换到的灵力约等于未入门段十四局、圆满段三局——**够把卡住的一次进度推过去，不够让人从此不闭关**。真正意义上的「用钱跳过等待」需要一次掏好几枚，而气海一次只装得下一枚（炼气 174），这条限制把兑换量天然压住了。

## 3. 兑换：灵石 → 灵力

| 项 | 规则 |
| --- | --- |
| 汇率 | `QI_PER_STONE = 100`，1 枚换 100 点 |
| 方向 | **只此一向**。反向（灵力换灵石）没有入口，也没有实现 |
| 入口 | 主页「灵石」那一格 → 兑换面板（`pages/index`，`exchangeQi()`） |
| 前提 ① | 灵石 ≥ 1 |
| 前提 ② | 气海空位 ≥ 100。装不下就换不成，**不会**按空位折算半份 |
| 粒度 | 一次一枚，可连点。气海装得下几枚，面板会写清 |
| 即时性 | 换来的灵力当场可用，不需要先打坐再收 |

**为什么单向，而且反过来永远不开**：

两个方向的后果完全不对称。

- **灵石买灵力 = 用钱买油。** 玩家省掉的是「等」，代价是攒不下功法，取舍还是取舍。
- **灵力换灵石 = 挂机时长直接印钱。** 气海一满就白坐着，玩家很快会发现最优解是「挂着不回来」；灵石从硬通货退化成计件工资，切磋这个系统也就可有可无了。

所以旧地基「互不兑换」换成了「只许单向汇出」：**灵力的入口被钱拓宽了，灵石的入口仍然是打出来的。**

**为什么卡在气海上，而不是卡在价格上**：如果兑换只看灵石够不够，钱就能买到「更大的油箱」——练真元、破境拓池这两件事会被钱绕过。现在钱能买油、买不来油箱，气海的每一格仍然只能靠境界与真元。

**为什么不做「按空位折算」**：玩家按的是一枚，扣的也该是一枚。扣一枚给 40 点，比直接说「装不下」更像骗人。

## 4. 单局耗气的算法

只有一个出处：`economy.practiceQiCost(o)`。

```
耗气 = RUN_QI[段]                          7 / 11 / 17 / 24 / 32
     × methodQiFactor(本门基准)              本门 base 30–56 → 0.85–1.30
     × TIER_QI[品阶]                        1.00 / 1.15 / 1.30 / 1.45
     × REALM_OVER（若境界超上限）            1.5
     × (1 − 心法省气，封顶 0.5)              静心 8% + 勘禁 10% + 九宫 9% + 并蒂 8% + 让路 8%
     ÷ 悟性系数 min(1.6, 1 + 悟性/200)       悟性 120 时 ×1.6 封顶
     × CROSS_QI（若本局换了门）              0.92
     → round，最低 1 点
```

**剑法·开锋斩桩诀（base 32）的五段实价：6 / 9 / 14 / 20 / 27**（黄阶、悟性 10、不换门）。

七门省气心法累加的上限是 50%：六门全学满也只有一半，防止以后再加功法把耗气叠穿；也让悟性仍然值得堆。

### 为什么单价随段上升，单点灵力的熟练度反而下降

| 段 | 实价 | 首局 S 熟练度 | 每点灵力换多少熟练度 |
| --- | --- | --- | --- |
| 未入门 | 6 | 34 | 5.67 |
| 入门 | 9 | 34 | 3.78 |
| 小成 | 14 | 34 | 2.43 |
| 大成 | 20 | 34 | 1.70 |
| 圆满 | 27 | 34 | 1.26 |

看起来「越后段越亏」。这是刻意的——**难盘该更贵**，否则「又便宜又给得多」会让后段只剩下挑战意义，玩家永远停在低关。

往上走的回报不在单价，在两处：

1. **连 S 只在当前关的 S 上叠**（`1.5^(k-1)`，10 层封顶，单局最高 1307 点）；
2. **回关按「本关 ÷ 当前关」折**（一次乘法、一次取整）。

于是「刷低关划不划算」这个问题没有答案：回关既叠不了连 S，又拿不满基础值。`npm run sim` 在固定 6000 点灵力预算下实测：逐段升 7290 点熟练度，而只刷第 1 关只剩 598 点、退一段也只有 598 点。

## 5. 为什么灵力有上限，灵石没有

这两条相反的设计，来自两种资源的**时间尺度不同**。

**灵力是日消耗**：一局 6–27 点，一天十局上下。没有上限时，挂机时长就是唯一的节奏——玩家只会「挂够再来」，而且挂到第 30 小时也没有新体验。加上气海之后，境界多了一重**每天摸得到**的意义（一趟能练几局），闭关也从「放着涨」变成「回来收」。

**灵石是长期目标**：一门玄阶功法 70 枚，破境 240 枚。给它设上限只会让玩家在接近上限时不敢打切磋——那是纯粹的负体验，不产生任何决策乐趣。无上限的代价是「后期灵石冗余」，由「破境价目递增」与「高阶功法只能靠掉落」对冲。

> 一句话：**油要有油箱，钱不需要钱包容量。**

## 6. 边界情况（都有实现与断言）

| 情况 | 规则 | 为什么 |
| --- | --- | --- |
| 灵力不足开一局 | 直接拒绝开局，回执给出差多少、气海上限、约坐几分钟可足 | 打完才告诉玩家「其实你没钱」是最差的体验 |
| 灵力不足切磋 | 拒绝，提示「先回洞府打坐」 | 同上 |
| 气海满时打坐 | **不挡**。仍可收，只回「灵力已满」，熟练度照给 | 打坐还产熟练度，那是另一条产出 |
| 气海满时领份例 | **拒绝**，回执写「先练一局腾出空位，份例在这等你」 | 一点空位都没有时领到的是 0，拒绝比「+0」诚实 |
| 气海只余一点时领份例 | **按空位领**，回执写「+21（气海只余 21 点，余下 39 散去）」 | 旧版是整份装不下就拒领，结果解锁的那一刻正好领不到——玩家以为是坏的 |
| 气海装不下兑换 | **拒绝**，面板写「先练一局把灵力用掉，再来换」 | 钱能买油，买不来更大的油箱 |
| 破境失败 | 灵石退一半（`BREAKTHROUGH_REFUND = 0.5`） | 阵基还在，灵石散了些 |
| 破境成功 | 灵石不退，气海当场补满 | 花出去就是花出去了；补满是「境界拓深」的即时回馈 |
| 走火 | 已扣的灵力不退 | 「走火」的分量就在这里 |
| 主动收功 | 灵力不退，连 S 归零 | 堵住「预感拿不到 S 就退出保连」 |
| 老档超上限 | 读档时夹平一次，不反复没收 | 旧版没有上限，老档可能攒到几百点 |
| 时钟倒退 | 闭关一分不给 | 改系统时间不能刷灵力 |

## 7. 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 灵力换灵石 | 挂机时长直接印钱。气海一满就白坐着，最优解变成「挂着不回来」，灵石从通货退化成计件工资。**这个方向永远不开** |
| 灵石买灵力（不做） | 旧版否掉的理由是「等于付费加速，会把气海变成付费点」。现在改为接受：灵石仍要打出来才换得到，气海也仍然卡着兑换量——买的是油，不是油箱 |
| 双向兑换 | 一旦双向，两种货币就退化成一种。所有「取舍」立刻消失，玩家只会找汇率最优路径 |
| 按空位折算兑换 | 扣一枚给半份，比直接拒绝更像骗人。要么整枚换得成，要么换不成 |
| 兑换不受气海限制 | 钱就买到了「更大的油箱」，练真元与破境拓池被绕过。气海的每一格只能靠境界与真元 |
| 灵力无上限 | 挂机时长成为唯一节奏，境界的第二重价值消失（见第 5 节） |
| 灵石也有上限 | 接近上限时不敢打切磋，纯负体验 |
| 参悟产出灵力/灵石 | 「花时间印钱」。灵力成过路财、灵石成计件工资，玩家一直在攒钱却感觉不到钱有分量。参悟因此**只耗不产** |
| 用灵力买功法 | 「用油买油」。功法只收灵石，`source.cost` 里没有灵力字段（`verify` 守着） |
| 首胜奖励也走 0.85 衰减 | 首胜是「打通这条路」的一次性奖励，与「重复刷」是两件事。混在一起会让玩家不敢打首胜（怕浪费衰减额度） |

## 8. 数值推导：为什么是这些数

| 常量 | 值 | 推导 |
| --- | --- | --- |
| `START_QI` | 160 | 开局气海 174，一进来就接近满——第一件事是「去练」而不是「先等半小时」 |
| `START_STONE` | 15 | 够打一场切磋就换第一门黄阶功法（最便宜的 16，差 1 枚；首胜另给 8 枚即可），让「置换」在第一小时发生 |
| `QI_PER_STONE` | 100 | 一枚换到的量 ≈ 未入门段十四局 / 圆满段三局：够推过一次卡点，不够从此不闭关。同时它正好大于炼气气海的一半，让「一次只能换一枚」成为自然节奏 |
| `qiPerMinute` | 0.5 | 一天 10–15 局的量级（困难 14 点/局 ≈ 240 点/8 小时）。旧版 1.2/分是「参悟产灵力、挂机只是贴补」时代的数，那时攒的灵力根本没处花 |
| ~~`profPerHour`~~ | 已删 | 曾给 2.5 点熟练度/时。关卡改由熟练度算出之后，挂机能推关卡——这一条整条删掉，闭关只产灵力 |
| `DAILY_QI` | 60 | 约三局小成段：补的是「今天练过了」，不是白送一笔钱 |
| `BATTLE_QI` | 5 | 让「赚灵石」和「练功」争同一池灵力。5 点约等于未入门段一局，打十场切磋 = 少练五局。养息式可把它抵到 2 点，封顶抵 3 |
| `BATTLE_STONE_DECAY` | 0.85 | 第 15 场只剩 10%，玩家自己会停手；不用硬性每日次数限制 |
| `FORTUNE_SCROLL_RATE` | 0.012 | 「一百局摸到一册」的量级。19 门靠机缘集齐要上千局，灵石买齐只要几百场切磋——机缘是盼头，不是主路 |
| `BREAKTHROUGH_STONE` | 60/120/240 | 逐境翻倍，与「一次破境 ≈ 一门玄阶功法」对齐 |
| `QI_CAP_PER_LING` | 2 | 真元 12 时给 24 点上限；真元百点时给 200 点——「练真元」因此值得专精 |
| `QI_CAP_SKILL_MAX` | 0.3 | 吐纳 10% + 太虚 15% = 25%，留 5% 余量；不给封顶以后加功法会撑穿 |

## 代码指路

- `data/economy.js` —— 全部常量与三个核心函数：`practiceQiCost()`、`qiCapOf()`、`qiFromStone()`
- `utils/game.js` —— `practiceCostOf()`（预判）、`applyPractice()`（实扣）、`battle()`（运功 2–5 点，另见 `moveBoard()` / `rollWithMoves()`）、`claimDaily()`、`settleOffline()`、`exchangeQuote()` / `exchangeQi()`（兑换的报价与执行，同一个 cap / room）
- `pages/index/` —— 兑换面板：点主页「灵石」那一格，`onExchange` 走 `commitCritical` 立即回写
- `data/skills.js` —— `source.cost.stone`（藏经阁价格）
- `data/opponents.js` —— `OPPONENTS` / `SECRET_REALMS` 的 `reward.stone`
- `scripts/simulate.js` —— 收支曲线与「三种刷法不反超」的断言
- `tests/game.test.js` —— 灵力不足拒绝开局、走火不退、首胜另给 8 枚、重复打赢衰减、份例按空位领、兑换 1:100 且不可逆

## 待验

- 全盘一次性灵石 466 枚 vs 需求 783 枚的缺口，靠重复切磋补需要多少场，尚未做过真人时长估算。兑换灵力成了第三条支出，这个缺口会更大。
- 0.85 衰减是「按当日第几场」还是「按当日第几场胜利」：实现取的是胜利场次计数，文案例写「当日第 n 场」。两者在连败时会不一致。
- 悟性 120 封顶 ×1.6 是理论值，实际靠哪些功法能堆到，未核算。
- **1:100 是不是给得太宽**：开局 15 枚灵石若全换成灵力是 1500 点，等于两百局未入门段——只是气海一次只装一枚，把它挡住了。若日后灵石来路变宽（充值 / 广告），这个比例必须重估。
- 兑换面板的入口是主页「灵石」数字那一格，热区只有一行；真人能不能发现，只能上手试。
