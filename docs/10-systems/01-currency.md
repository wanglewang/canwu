# 双货币体系：灵力是油，灵石是钱

> 两种货币不是「两种钱」，是**两种性质完全不同的资源**。灵力是会耗尽的燃料，灵石是能存住的通货。它们之间没有汇率，也没有兑换入口——这条是整套经济的地基。

---

## 1. 一句话

**灵力管「今天能练几局」，灵石管「能换到什么」。**

- 灵力只从**时间**来（闭关、份例），只往**运功**去（参悟、切磋、秘境）。
- 灵石只从**对战**来（切磋、秘境），只往**购置**去（功法、破境）。

两条线在入口与出口上完全不交叉。玩家手上永远只有一种选择：**这一池灵力，是拿去练功，还是拿去挣盘缠。**

## 2. 两张表

### 灵力（油）

| 项 | 内容 |
| --- | --- |
| 来源 ① | 闭关：0.5 点/分钟，一次最多算 8 小时（产能 240 点），可随时「打坐」当场收 |
| 来源 ② | 每日份例：当日参悟满 3 次，领灵力 +60（灵石 0） |
| 消耗 ① | 参悟：每局 6–27 点（见下表），开局即扣，走火与收功都不退 |
| 消耗 ② | 切磋：每场运功 5 点（养息式最多抵 3 点，实扣 2–5），胜负都扣，不够直接拒绝开打 |
| 消耗 ③ | 秘境：每场运功 5 点，同上（与切磋共用同一套三式） |
| 上限 | **有**。气海 =（境界基数 + 真元×2）×（1 + 心法扩池 ≤30%）；炼气 174 起 |
| 溢出 | 满则不再生。闭关坐出来的超出上限部分**当场散掉**，回执写明「气海已满，散去 N 点」 |
| 可交易性 | 无。不能换灵石，也不能被赠送 |

### 灵石（钱）

| 项 | 内容 |
| --- | --- |
| 来源 ① | 切磋：7 位对手 12 / 18 / 26 / 36 / 50 / 70 / 120 |
| 来源 ② | 秘境：3 处 8 / 16 / 30 |
| 来源 ③ | 首胜（切磋）/ 首过（秘境）另给 **8** 枚，一次性 |
| 衰减 | 当日第 n 场：`0.85^(n-1)`。第 1 场全额，第 5 场 52%，第 10 场 23%，第 15 场约 10% |
| 消耗 ① | 藏经阁功法：12 门，16–70 枚（见下表） |
| 消耗 ② | 破境布阵：60 / 120 / 240（筑基 / 金丹 / 元婴）；失败退一半 |
| 上限 | 无。攒着不咬手 |
| 可交易性 | 无（只有战力码可分享，不含灵石） |

## 3. 单局耗气的算法

只有一个出处：`economy.practiceQiCost(o)`。

```
耗气 = RUN_QI[档]                          7 / 11 / 17 / 24 / 32
     × methodQiFactor(本门基准)              本门 base 30–56 → 0.85–1.30
     × TIER_QI[品阶]                        1.00 / 1.15 / 1.30 / 1.45
     × REALM_OVER（若境界超上限）            1.5
     × (1 − 心法省气，封顶 0.5)              静心 8% + 勘禁 10% + 九宫 9% + 并蒂 8% + 让路 8%
     ÷ 悟性系数 min(1.6, 1 + 悟性/200)       悟性 120 时 ×1.6 封顶
     × CROSS_QI（若本局换了门）              0.92
     → round，最低 1 点
```

**剑法·开锋诀（base 32）的五档实价：6 / 9 / 14 / 20 / 27**（黄阶、悟性 10、不换门）。

七门省气心法累加的上限是 50%：六门全学满也只有一半，防止以后再加功法把耗气叠穿；也让悟性仍然值得堆。

### 为什么单价随档上升，单点灵力的熟练度反而下降

| 档 | 实价 | 首局 S 熟练度 | 每点灵力换多少熟练度 |
| --- | --- | --- | --- |
| 简单 | 6 | 34 | 5.67 |
| 普通 | 9 | 34 | 3.78 |
| 困难 | 14 | 34 | 2.43 |
| 极难 | 20 | 34 | 1.70 |
| 绝境 | 27 | 34 | 1.26 |

看起来「越高档越亏」。这是刻意的——**难盘该更贵**，否则「又便宜又给得多」会让高档只剩下挑战意义，玩家永远停在低档。

往上走的回报不在单价，在两处：

1. **连 S 只在本门最高已解锁档叠**（`1.5^(k-1)`，10 层封顶，单局最高 1307 点）；
2. **低档按档差折半**（每低一档 ÷2 后四舍五入）。

于是「哪档划算」这个问题没有答案：停在低档既叠不了连 S，又拿不满基础值。`npm run sim` 在固定 6000 点灵力预算下实测：逐档升 7290 点熟练度、退一档刷 6937 点、只刷简单 6392 点。

## 4. 为什么灵力有上限，灵石没有

这两条相反的设计，来自两种资源的**时间尺度不同**。

**灵力是日消耗**：一局 6–27 点，一天十局上下。没有上限时，挂机时长就是唯一的节奏——玩家只会「挂够再来」，而且挂到第 30 小时也没有新体验。加上气海之后，境界多了一重**每天摸得到**的意义（一趟能练几局），闭关也从「放着涨」变成「回来收」。

**灵石是长期目标**：一门玄阶功法 70 枚，破境 240 枚。给它设上限只会让玩家在接近上限时不敢打切磋——那是纯粹的负体验，不产生任何决策乐趣。无上限的代价是「后期灵石冗余」，由「破境价目递增」与「高阶功法只能靠掉落」对冲。

> 一句话：**油要有油箱，钱不需要钱包容量。**

## 5. 边界情况（都有实现与断言）

| 情况 | 规则 | 为什么 |
| --- | --- | --- |
| 灵力不足开一局 | 直接拒绝开局，回执给出差多少、气海上限、约坐几分钟可足 | 打完才告诉玩家「其实你没钱」是最差的体验 |
| 灵力不足切磋 | 拒绝，提示「先回洞府打坐」 | 同上 |
| 气海满时打坐 | **不挡**。仍可收，只回「灵力已满」，熟练度照给 | 打坐还产熟练度，那是另一条产出 |
| 气海满时领份例 | **拒绝领取**（余位不足 60 时） | 份例是发放的，可以等人来取；打坐收的是坐出来的，满溢就散 |
| 破境失败 | 灵石退一半（`BREAKTHROUGH_REFUND = 0.5`） | 阵基还在，灵石散了些 |
| 破境成功 | 灵石不退，气海当场补满 | 花出去就是花出去了；补满是「境界拓深」的即时回馈 |
| 走火 | 已扣的灵力不退 | 「走火」的分量就在这里 |
| 主动收功 | 灵力不退，连 S 归零 | 堵住「预感拿不到 S 就退出保连」 |
| 老档超上限 | 读档时夹平一次，不反复没收 | 旧版没有上限，老档可能攒到几百点 |
| 时钟倒退 | 闭关一分不给 | 改系统时间不能刷灵力 |

## 6. 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 灵力换灵石（或反向） | 一旦可兑换，两种货币就退化成一种，所有「取舍」立刻消失。玩家只会找汇率最优路径，两个系统变成一个数值 |
| 灵石买灵力（加速道具） | 等于付费加速，会把「气海」变成付费点；本项目无商业化，也不该有这条路 |
| 灵力无上限 | 挂机时长成为唯一节奏，境界的第二重价值消失（见第 4 节） |
| 灵石也有上限 | 接近上限时不敢打切磋，纯负体验 |
| 参悟产出灵力/灵石 | 「花时间印钱」。灵力成过路财、灵石成计件工资，玩家一直在攒钱却感觉不到钱有分量。参悟因此**只耗不产** |
| 用灵力买功法 | 「用油买油」。功法只收灵石，`source.cost` 里没有灵力字段（`verify` 守着） |
| 首胜奖励也走 0.85 衰减 | 首胜是「打通这条路」的一次性奖励，与「重复刷」是两件事。混在一起会让玩家不敢打首胜（怕浪费衰减额度） |

## 7. 数值推导：为什么是这些数

| 常量 | 值 | 推导 |
| --- | --- | --- |
| `START_QI` | 160 | 开局气海 174，一进来就接近满——第一件事是「去练」而不是「先等半小时」 |
| `START_STONE` | 15 | 够打一场切磋就换第一门黄阶功法（最便宜的 16，差 1 枚；首胜另给 8 枚即可），让「置换」在第一小时发生 |
| `qiPerMinute` | 0.5 | 一天 10–15 局的量级（困难 14 点/局 ≈ 240 点/8 小时）。旧版 1.2/分是「参悟产灵力、挂机只是贴补」时代的数，那时攒的灵力根本没处花 |
| `profPerHour` | 2.5 | 8 小时 20 点熟练度，约等于打半局。挂机能练，但远不如真打 |
| `DAILY_QI` | 60 | 约三局困难档：补的是「今天练过了」，不是白送一笔钱 |
| `BATTLE_QI` | 5 | 让「赚灵石」和「练功」争同一池灵力。5 点约等于简单档一局，打十场切磋 = 少练五局。养息式可把它抵到 2 点，封顶抵 3 |
| `BATTLE_STONE_DECAY` | 0.85 | 第 15 场只剩 10%，玩家自己会停手；不用硬性每日次数限制 |
| `FORTUNE_SCROLL_RATE` | 0.012 | 「一百局摸到一册」的量级。19 门靠机缘集齐要上千局，灵石买齐只要几百场切磋——机缘是盼头，不是主路 |
| `BREAKTHROUGH_STONE` | 60/120/240 | 逐境翻倍，与「一次破境 ≈ 一门玄阶功法」对齐 |
| `QI_CAP_PER_LING` | 2 | 真元 12 时给 24 点上限；真元百点时给 200 点——「练真元」因此值得专精 |
| `QI_CAP_SKILL_MAX` | 0.3 | 吐纳 10% + 太虚 15% = 25%，留 5% 余量；不给封顶以后加功法会撑穿 |

## 代码指路

- `data/economy.js` —— 全部常量与两个核心函数：`practiceQiCost()`、`qiCapOf()`
- `utils/game.js` —— `practiceCostOf()`（预判）、`applyPractice()`（实扣）、`battle()`（运功 2–5 点，另见 `moveBoard()` / `rollWithMoves()`）、`claimDaily()`、`settleOffline()`
- `data/skills.js` —— `source.cost.stone`（藏经阁价格）
- `data/opponents.js` —— `OPPONENTS` / `SECRET_REALMS` 的 `reward.stone`
- `scripts/simulate.js` —— 收支曲线与「三种刷法不反超」的断言
- `tests/game.test.js` —— 灵力不足拒绝开局、走火不退、首胜另给 8 枚、重复打赢衰减

## 待验

- 全盘一次性灵石 466 枚 vs 需求 783 枚的缺口，靠重复切磋补需要多少场，尚未做过真人时长估算。
- 0.85 衰减是「按当日第几场」还是「按当日第几场胜利」：实现取的是胜利场次计数，文案例写「当日第 n 场」。两者在连败时会不一致（连败不消耗衰减额度，这可能是有利的松绑，也可能是文案需要改）。
- 悟性 120 封顶 ×1.6 是理论值，实际靠哪些功法能堆到，未核算。
