# 仙榜、切磋、秘境（三个社交页）

> 三页各说一件事：榜上我第几、跟谁打、去哪探。**不互相开入口行**——指向由「本页说明」承担。

## 核心前提：三个社交页，各管一个念头

我先替玩家把这三个页面分开：「想知道自己排第几」「想找个具体的人打一场」「想去个地方探一探」。这是三个不同的念头，所以我拆成三页——曾经把它们挤在一起，玩家得先分清哪一段是同门、哪一段是秘境，才能下手，那个犹豫本身就是成本。

三页共享一条纪律：首屏先给战力。因为不管是比榜、切磋还是探秘境，打架前都得先看清自己几斤几两。然后每一条对手或秘境都要在一行里说清战力、能不能打、花多少、得多少——玩家不该点进去才发现「打不起」。

我还刻意不让三页互相开「去那页」的入口行。六宫格已经是导航中枢，再开一遍就是重复；指向这种事，交给「本页说明」就够了。

## 1. 概述

- **战力仙榜**：只回答「我排第几、跟我最接近的是谁」；
- **仙门切磋**：七位同门对手 + 一个战力码；
- **秘境探索**：三处秘境，只出灵石不掉功法。

## 2. 目标与非目标

**目标**

- 每页首屏先给「我的战力」，因为打架前必看；
- 每个对手 / 秘境一行说清：战力、能不能打、这一场花多少、得多少；
- 结算卡共用一份（`components/duel-result`）。

**非目标**

- 不在切磋页里放秘境列表（历史问题，已拆）；
- 不在秘境页里放对手（同上）；
- 不在页面之间互相开「去那页」的入口行。

## 3. 战力仙榜 `pages/board`

```
我的战力                            初入仙门
96
筑基                                榜上第 3
[ 与 某某 切磋 ]
前 十
1  长风     筑基   170
2  阿吉     筑基   132
3  青衫客 · 我  筑基  96     ← imm-row--on（金边）
...
```

| 元素 | 说明 |
| --- | --- |
| `myRank > 0` | 显示「榜上第 N」，否则「还没上榜」 |
| 「前十」 | 只取 `rows.slice(0, 10)` |
| `imm-row--on` | 自己那一行带左侧 4rpx 金边 + 名字转金 |
| 前三名 | `.imm-row__rank--top`，金色加粗 |
| 「与 X 切磋」 | 仅当 `pickRival` 找到对手 |

### 3.1 三个状态

| 状态 | 呈现 |
| --- | --- |
| `loading` | `.state.state--inline` + 「读取中」 |
| `error` | `.state.state--inline` + 错误信息 + 「重试」链接 |
| 正常 | `.imm-list` 十行 |

**榜单不可用不是白屏**：`social.refreshBoard` 失败时给一行说明与重试，不阻塞页面其余部分（`refreshMe` 与 `loadBoard` 是两件独立的事）。

### 3.2 榜上的切磋只给 toast

`onFight` → `engine.battleRival` → toast「胜 · 96 : 84」。**不出结算卡**。

这是与切磋页的差别：榜上的对手是「远处的人」，打一场只是比一比；切磋页的对手是「有名字、有风味句、有掉落」的同门，值得一张完整的卡。

## 4. 仙门切磋 `pages/battle`

```
我的战力                            初入仙门
96
筑基 · 灵力 61 / 174          战力仙榜 ›
同门对手
张三  已首胜
一场没打过的新人，剑还没开锋
战力 84   可胜
首胜掉落《太虚照见诀》                        [挑战]
李四  外门弟子
...
────────────────────────
切磋论道
战力码                                展开
[我的战力码 CW1-xxxx]
[复制我的战力码]  [粘贴来码] [与之过招]
```

### 4.1 一行说清七件事

| 元素 | 类 | 内容 |
| --- | --- | --- |
| 名字 | `.imm-row__name` | — |
| 状态胶囊 | `.imm-chip` / `--jade` | 已首胜 / 称号 |
| 风味句 | `.riv-desc`（单行省略） | 一句话人设 |
| 战力 | `.riv-meta` | 数字 |
| 形势 | `.riv-tone--good` / `--warn` | 「可胜」/「难胜」 |
| 掉落 | `.riv-drop`（金） | 首胜掉落《…》/ 已得，再战只给灵石 |
| 代价 | `.riv-note` | 运功 −5 灵力 · 灵石 +8（今日第 3 场 ×0.72） |

**风味句退到注脚色、战力与形势提亮一段**：两行同色同号时四行字会糊成一段，看不出哪行是能决策的信息。

### 4.2 灵力余量必须摆在首屏

「这一页每打一场都扣 5 点，玩家要一眼看出还能打几场」。

所以 `.imm-strip` 写的是 `筑基 · 灵力 61 / 174`，而不是只写境界名。

### 4.3 灵石衰减要写清

```
运功 −5 灵力 · 灵石 +8（今日第 3 场 ×0.72）
```

`stoneFactor < 1` 才追加括号。**不写清，玩家会以为赢了却少给了。**

### 4.4 战力码

- 「我的战力码」：`CW1-...`，复制到剪贴板（过 `privacy.guard`）；
- 「粘贴来码」+「与之过招」：打的是对方的**镜像**，不用同时在线。

镜像战同样出结算卡（`duel-result`），因为它是「一个具体的人」。

### 4.5 页尾两条链接

```
此处说明 · 完整规则 ›
```

两条都是「看规则」，合成一行，**不在页尾排两段同类链接**。

## 5. 秘境探索 `pages/secret`

```
我的战力                            初入仙门
96
筑基 · 灵力 61 / 174        不掉功法，只出灵石
秘境
雾隐谷  未走通
一处只在下雨后现形的山谷
战力 84   可过
首次走通再 +8 灵石 · 运功 −5 灵力 · 灵石 +8   [入秘境]
```

与切磋的**三处不同**：

| | 切磋 | 秘境 |
| --- | --- | --- |
| 对象 | 人（有名字、称号、风味句） | 地方 |
| 首胜措辞 | 「首胜」 | 「首过」 |
| 掉落 | 首胜给功法 | 只出灵石，不掉功法 |

**共用**：`battleWins` 衰减计数。两个页面的「今日第 n 场」是同一个计数器——同一天打三场切磋再打一场秘境，秘境就是第 4 场。

这是刻意的：衰减针对的是「今天打了多少场」，不是「在哪个页面打的」。

### 5.1 措辞对照

| 位置 | 切磋 | 秘境 |
| --- | --- | --- |
| 状态胶囊 | 已首胜 / 未胜 | 已走通 / 未走通 |
| 按钮 | 挑战 / 再战 | 入秘境 / 再入 |
| 结算标题 | `首胜 · 名字` | `首过 · 名字` |

`duel-result` 里用 `r.kind === 'secret' ? '首过 · ' : '首胜 · '` 一处判断。

## 6. 结算卡（三页共用一份）

`components/duel-result`，`styleIsolation: 'apply-shared'`。

七行内容与字段来源见 `03-components.md`。这里只记三条设计判断：

1. **比数要摆出来**：`我方挥出 96` vs `对方接下 84`，而不是只说「胜」——`rollBattle` 有 ±15% 波动，玩家需要看到这一局的骰子；
2. **资源分行**：灵力 −5（付出去）、灵石 +8（挣回来），分开写；
3. **特效行**：本门功法的 `power / variance` 特效在结算里逐条列出，否则玩家不知道特效有没有生效。

## 7. 被否决的方案

这批否决其实在回答同一个问题：三个社交页的边界该划在哪。把它们挤在一页、互相开入口、让榜上也出结算卡——都是想「省一步」，结果是把三个清清楚楚的念头搅成一团。我宁可多一页，也不让玩家多一次犹豫。

| 方案 | 为什么否掉 |
| --- | --- |
| 切磋与秘境挤在一页 | 首屏得先分清「哪一段是同门」才能点 |
| 三页互相开「去那页」入口 | 与六宫格重复；指向交给「本页说明」 |
| 榜上切磋也出结算卡 | 榜上是「远处的人」，只需要一个比分 |
| 秘境掉落功法 | 与切磋的奖励结构重复，两条线都在发功法就没有区别 |
| 秘境用独立衰减计数 | 「今天打了多少场」是一个概念，不该按页面分 |
| 风味句与战力同色 | 四行字糊成一段 |
| 衰减不写倍率 | 玩家以为少给了 |

## 9. 待验

- 榜上切磋只给 toast，**没有「对方是谁、差多少」的细节**——若玩家抱怨「不知道怎么就输了」，需要给它一张简化卡。
- `pickRival` 选的是「最接近我战力」的人。若榜上只有自己一个人，`rival` 为 null，按钮消失、页面没有说明「为什么没有对手」。
- 秘境与切磋共用 `battleWins`：玩家可能在秘境页看到「今日第 4 场」而以为秘境自己计过三次。**这条目前只靠「今日第 n 场」的措辞兜，没有页面级解释**。
- 战力码是 `CW1-` 前缀，存档码是 `CANWU1:` 前缀，两个长得很像但用途完全不同，输入框的 placeholder 分别写了，仍可能混。
- 三页的页尾都只有「此处说明」，没有「完整规则」的只有仙榜——一致性上略有差异。
