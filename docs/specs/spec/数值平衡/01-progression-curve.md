# 需求（Spec）· 进度曲线：两条毕业路径与一个 6000 点预算实验

> 同一个 99999，全 C 要 **10000 局**，全程不断 S 只要 **84 局**。中间那 119 倍，就是这套熟练度体系的全部设计。

## 核心前提：把「会打」和「打得稳」拆成两件事

我想让熟练度回答一个问题：这一局，玩家到底练出了什么。如果把「评级」和「连 S」揉成一个数，玩家只知道「我涨了多少」，不知道「为什么涨这么多」。所以我把它拆成两条正交的轴——评级是操作水平的函数，连 S 是连续性的函数，两者相乘。

拆开之后，一个刻意的结果浮现出来：全 C 要 10000 局，全程不断 S 只要 84 局。这 119 倍不是我定的目标，是两条曲线的自然结果。我定的目标只有两句——「S 比 C 值钱得多」+「连着 S 比断着 S 值钱得多」，两个乘数一叠就到了这个量级。

这也是我最看重的一处设计：玩家的努力方向被这把尺子说清楚了。想省时间，光「多打几局」没用（门槛加速扩张），得「打得好」且「连着打」。经济系统里所有「别刷简单关」的规矩，根都扎在这里。

## 1. 概述

熟练度只由「评级 + 连 S 层数」决定。评级是操作水平的函数，连 S 是连续性的函数——两者乘起来，把「会打」与「打得稳」拆成两条正交的轴。

这套「两条轴咬合」的形状画出来是这样——评级决定基数，连 S 决定倍率，两队人马从同一条起跑线出发，终点却差了 119 倍：

```text
   评级（操作水平）          连 S（连续性）
   C / B / A / S ─┐         连 1 / 3 / … / 10 层
       ↓          │              ↓
    单局基数       │          连 S 倍率（10 层封顶）
       └───────────┴──────┬───────────┘
                          ▼
                 熟练度 = 基数 × 倍率
                          │
      ┌───────────────────┴───────────────────┐
   全程 C                                 全程不断 S
   10000 局 / 265020 灵力                 84 局 / 896 灵力
      └───────────────────┬───────────────────┘
                      同一个终点 99999
```
*（结构示意，非实测截图；只示意两条轴如何相乘，具体数值见下方实测表。）*

| | 局数 | 灵力 | 闭关时长 |

| 全 C | 10000 | 265020 | 8834 小时 |

**119 倍不是设计目标，是两条曲线的自然结果**。设计目标是「S 比 C 值钱得多」+「连着 S 比断着 S 值钱得多」，两个乘数一叠就到了 119 倍。

### 2.1 六段门槛

| 段位 | 门槛 | 全 C 局数 | 全 S 局数 |
| --- | --- | --- | --- |
| 生涩 | 0 | — | — |
| 初窥 | 300 | 30 | 5 |
| 渐熟 | 1500 | 150 | 8 |
| 精纯 | 6000 | 600 | 12 |
| 通玄 | 24000 | 2400 | 26 |
| 化境 | 99999（硬顶） | 10000 | 84 |

**门槛是 1 : 5 : 20 : 80 : 333**（相对第一段），刻意做成加速扩张：越往后，靠「多打几局」越不划算，只能靠「打得好且连着打」。

## 3. 连 S 曲线

```
第 1～10 连：34 / 51 / 77 / 115 / 172 / 258 / 387 / 581 / 871 / 1307
一轮（10 连）= 3853 点
第 11 连起锁死 1307
```

`comboGain(k) = round(34 × 1.5^(k-1))`，`COMBO_MAX = 10`。

**两条取整纪律**（`game.test.js` 守着）：

1. 每局独立从 34 起算一次取整——第 3 连取 **77**（`34×1.5^2 = 76.5 → 77`），不是 76；
2. **不拿上局整数接着乘**——第 4 连是 `round(34×1.5^3) = 115`，不是 `round(77×1.5) = 116`。

第 2 条尤其重要：拿上局整数接着乘会让误差累积，第 10 连会差出几十点。

### 3.1 一轮 3853 点意味着什么

3853 点 ≈ 一个「小成 → 大成」门槛（4500）的 86%。

也就是说：**打满一轮 10 连 S，几乎等于一整段跨越**。这是「连 S 比单局评级更重要」的量化表达。

### 3.2 断连的代价

断一次（非 S / 失败 / 主动结束），下一局从 34 重起。

从第 10 连（1307）掉回第 1 连（34），损失是 **97%** 的单局收益。这就是「连 S 是本作最贵的资源」的含义。

## 4. 回关折减：一根连续尺子

```
levelFactor(本关, 当前关) = (本关 ÷ 当前关) × (本关段基数 ÷ 当前关段基数)
当前第 40 关（入门段 11）：40 ×1.000 / 30 ×0.750 / 20 ×0.500 / 10 ×0.159 / 1 ×0.016
profByLevel(base, 关, 当前关) = round(base × levelFactor)
```

两条纪律：

1. **只乘一次、只取整一次**——玩家按「34 × 20 ÷ 40 = 17」能复算；
2. **耗气不跟着折**——按回关所在段的基数算（未入门 7 点起）。**正因为这一条不折，第二把尺子（段基数比）才必须有**：回关省下的那口气，要在熟练度那头折回来。

**回关局不叠连 S 层数**（用户拍板）：不叠层、不砍连击收益、已有层数原样保留。两套机制**不许串联取整**。

为什么不用「每低一段折半」：段位只有五段，同一段里第 1 关与末关的系数都是 1（小成段 150 关都拿 1.0），而段内第 1 关的 S 率远高于末关——**段内折减是空的**。按关折才连续：退一关只掉不到 1%。

## 5. 6000 点预算实验

固定 6000 点灵力（≈ 闭关 200 小时），五种刷法：

| 刷法 | 局数 | 熟练度 | 平均每点灵力 |
| --- | --- | --- | --- |
| 黄阶 · 只刷第 1 关 | 1000 | **11551** | 1.93 |
| 黄阶 · 逐关进 | 376 | 6399 | 1.07 |
| 黄阶 · 退一章 | 1000 | 11551 | 1.93 |
| 地阶 · 逐关进 | 251 | 4592 | 0.77 |
| 黄阶 · 金丹后 | 270 | 4910 | 0.82 |

### 5.1 四个结论

1. **只刷第 1 关反超（11551）**：模拟打法下低关省下的气盖过回关折减，逐关进只有 6399；旧版「逐关进 7290 / 只刷第 1 关 598」的结论已作废；
2. **退一章与只刷第 1 关同分（11551）**：两条都在低关圈里打转，随机评级下收益一样；
3. **品阶加价是真的（地阶 4592 vs 黄阶 6399）**：地阶耗气更贵，同样的气只换来约 72% 的熟练度；天阶功法已于 2026-11 退役，拿天阶做对照的旧句一并作废；
4. **「不许反超」这条护栏已废**：`scripts/simulate.js` 的预算段只断言三条曲线不倒挂到不可读，不再断言逐关进必胜。

### 5.2 金丹后练黄阶（4910）

境界超过功法的 `maxRealm` 时，耗气 ×1.5。同样的气只拿到约 77% 的熟练度。

**这是「往上走之后该换功法」的硬约束**：金丹期还抱着黄阶练，效率掉两成。

## 6. 三条守恒关系

| 关系 | 内容 |
| --- | --- |
| 熟练度 ↔ 灵力 | 熟练度只吃灵力，不吃灵石 |
| 灵石 ↔ 战力 | 灵石只买功法与布阵，不买熟练度 |
| 参悟只耗不产 | 参悟**不产任何资源**（`resMult / MAX_MULTIPLIER` 已整条退役） |

**「参悟不产资源」是这套经济的地基**。它一旦松动，玩家就会找到「用参悟刷灵石」的路，两条货币线当场糊掉。

## 7. 曲线为什么是「加速扩张」而不是「线性」

线性门槛（每段 +3000）会让「多打几局」永远有效。结果是：玩家不需要提高水平，只需要多花时间。

加速扩张（1 : 5 : 20 : 80 : 333）把「时间」的边际收益压到很低：
- 从「初窥」到「渐熟」只需多 120 局；
- 从「通玄」到「化境」要多 7600 局；火候名按熟练度，与关卡段位（未入门/入门/小成/大成/圆满）是两套尺子。

于是玩家在大成之后必须转向「提高评级」与「保持连续」，而不是「再刷几百局」。

## 8. 被否决的方案

这一组否决讲的是同一个道理：**熟练度这把尺子只能量「练得怎么样」，不能掺进别的东西**。乘品阶、乘境界、乘悟性，都是在往这把尺子里塞第二件事，结果要么逼玩家只练天阶、要么让「境界是上限」变成空话、要么让悟性双重收益。旧版还想「把刷第 1 关堵死」，但模拟打法证明它堵不死（见 §5.1）；现在的说法改为：连 S 只在当前关叠、回关折减生效，但低关省气仍可能反超，这是待观察的取舍，不是已经解决的问题。

| 方案 | 为什么否掉 |
| --- | --- |
| 熟练度乘品阶倍率 | 会让「练天阶」变成唯一正确选择，黄阶功法失去存在意义 |
| 熟练度乘境界倍率 | 与「境界是上限而非收益」冲突 |
| 熟练度乘属性（悟性） | 悟性已经负责「省灵力」，再让它加熟练度就是双重收益 |
| 按段折（旧版） | 段位只有五段，段内第 1 关与末关系数都是 1，段内折减是空的 |
| 回关也叠连 S | 会让「刷第 1 关」反超逐关进，最优策略变成「打最简单的」 |
| 线性门槛 | 「多花时间」永远有效，水平不重要 |
| 参悟产灵石 | 两条货币线当场糊掉 |
| 三连 S 直接晋级 | 已整体退役：它让「稳」比「好」更值钱，与连 S 倍率的意图冲突 |

## 10. 待验

- **`GRADE_DIST` 从未用真机数据校准**。两条毕业曲线的「84 局」与「10000 局」完全建立在「未入门段 25% 拿 S」这种假设上。真机数据回来后，这一整篇的结论都要复算。
- 「119 倍」是**全 C 与全 S 的极端对比**。中间形态（比如「六成 S、四成 A」）的实际曲线上没有算过——它可能更接近现实，但 sim 没输出这一段。
- 六段门槛 1 : 5 : 20 : 80 : 333 的比例是手定的，**没有依据说明为什么是 5 而不是 4 或 6**。
- 回关折减「退一关只损失不到 1%」是否足够让玩家感知到「退远很亏」，需要真机数据。
- 「一轮 10 连 = 3853 = 86% 的一段跨越」这个巧合是否有意设计，代码与文档里都没有记录。
