# 需求（Spec）· S · 经济契约

> 回答：**灵力和灵石怎么分、怎么换、每局花多少。**
> 受 `constitution/README.md` 约束。只写可测行为，数值指真源。

## 契约与守卫

- **两笔钱分清楚**：灵力是每局消耗的油，灵石是买东西的钱，二者不可混算。
- **兑换单向**：只允许灵石换灵力，反向永远不开。
  **守卫**：`data/economy.js` 的 `QI_PER_STONE` 与文件头理由 + `scripts/verify.js`。
- **每局耗气有定价表**：按段位取值，六项连乘、有下限，付不起不开局。
  **守卫**：`data/economy.js` 的 `RUN_QI` 与 `qiCap` 公式 + `scripts/simulate.js` 耗气断言。
- **熟练度不产资源**：参悟只推进火候与关数，不掉落灵石。
- **气海有上限**：灵力上限由境界基数、真元和扩池决定；老档超出上限在读档时夹平。
  **守卫**：`data/economy.js` 的 `qiCap` 公式 + `tests/store.test.js`。

## 外部依赖

`data/economy.js`（兑换、耗气、气海）、`data/world.js`（属性）、`scripts/verify.js`。
