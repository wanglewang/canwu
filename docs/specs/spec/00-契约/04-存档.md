# 需求（Spec）· S · 存档契约

> 回答：**存档怎么读、老档怎么升、异常路径怎么处理。**
> 受 `constitution/README.md` 约束。只写可测行为。

## 契约与守卫

- **老存档能升级**：新字段补默认值，不改版本号也能读旧档；超出上限的值在读档时夹平。
  **守卫**：`tests/store.test.js` + `utils/game/state.js` 的 `normalizeState`。
- **读档不发钱**：读档只恢复状态，不重新发放奖励或资源。
  **守卫**：`tests/store.test.js`。
- **局中切页作废**：离开参悟页后该局不保留，回来要重新开始。
  **守卫**：页面逻辑 + `tests/store.test.js`。
- **领奖不许因装不下而整份拒绝**：按空位收多少算多少，并告诉玩家散掉多少。
  **守卫**：`tests/game.test.js` + 奖励领取逻辑。

## 外部依赖

`utils/game/state.js`（normalizeState）、`tests/store.test.js`、云端同步适配。
