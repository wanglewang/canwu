## 玩法概述

把牌面朝下摊开，每张底下压着一个卦象。你翻两张，卦象相同就通一对、永久留在盘上；不同就阖回去——
不扣心神、不扣分，只是那两次翻牌的时间白花了。所以这一门的惩罚只有一种：慢。

我想让玩家把注意力全放在「记」上：记住哪个卦象在哪儿，再一对对配出来。这也是我把 S 做成全站唯一双条件的原因——
既要快、又不能乱翻。快但乱翻不行，稳但磨蹭也不行，两条都卡着「记」这一个字。

```text
   ↘ 翻两张，卦象相同才通一对；翻错只是阖上
   ┌────┬────┬────┬────┐
   │ 乾 │  ▢ │  ▢ │ 坤 │  ▢ 面朝下 · 乾/坤 卦象
   ├────┼────┼────┼────┤  翻开 → 记住位置 → 配对
   │  ▢ │ 离 │  ▢ │  ▢ │  停留 flipMs 后阖上
   ├────┼────┼────┼────┤  翻错：两张阖上，只费时间
   │  ▢ │  ▢ │ 乾 │  ▢ │
   ├────┼────┼────┼────┤
   │ 离 │  ▢ │  ▢ │  ▢ │
   └────┴────┴────┴────┘
   S 要同时达标：快 + 准（对数 × 4 翻以内）
```

这篇只写五段共用的骨架。对数与手感每段一篇，数字不在这里。

## 1. 盘面介绍

4 列方格，行数随对数变化（5 对 = 10 张 → 4×3，8 对 = 16 张 → 4×4）。

- 每张牌面是一个卦象（`SIGNS` 共 8 个：乾 / 坤 / 震 / 巽 / 坎 / 离 / 艮 / 兑）；
- 翻开停留 `flipMs`，随后阖上；
- 盘面不写汉字，卦象用 `emblem` 图案。

## 2. 规则说明

| 项 | 规则 |
| --- | --- |
| 通一对 | 连翻两张同卦象 → 这一对永久通开 |
| 翻错 | 两张阖上，**多记两次翻牌**，白费时间 |
| 时限 | `timeLimit`，到点还没全通 → **失败 F** |
| 入定（提示） | 照见一对（直接把两张亮出来） |

**翻错不罚任何东西，除了时间**。这一门的惩罚只有一种：慢。
（原文一句话内核写「多记一次翻牌」、规则表写「多记两次翻牌」，两处口径不一，此处按规则表照录，不替它抹平。）

### 2.1 评级：全站唯一的双条件

按「解完全部对子的用时」，**S 另有翻牌次数要求**：

| 段 | S | A | B |
| --- | --- | --- | --- |
| 条件 | ≤18 秒 且 ≤对数×4 翻 | ≤30 秒 | ≤46 秒 |

**S 是双条件**：18 秒内 + 翻牌次数不超过「对数 × 4」。前者考记忆广度，后者考记忆准确度——
快但乱翻不行，稳但磨蹭也不行。这也是全站唯一一个「评级含双条件」的玩法，界面上需要注意表达（见 §7）。

## 3. 五段递进

每一段换的是**对数与记忆停留**，不是惩罚方式：

| 段 | 这一段新学的一件事 | 主轴 |
| --- | --- | --- |
| 一 · 未入门 | 5 对、停留 1.00 秒、70 秒、照见 3 次：认识「翻错只费时间」，记位置 | 记忆广度 |
| 二 · 入门 | 6 对、停留 0.85 秒：候选多一对，短时记忆开始吃力 | 记忆广度 |
| 三 · 小成 | 7 对、停留 0.75 秒：7 对是长平台（大成仍是 7 对），靠停留收窄 | 记忆精度 |
| 四 · 大成 | 仍是 7 对，停留收到 0.66 秒；留影登场：照见不再被计时器掐头去尾 | 记忆精度 |
| 五 · 圆满 | 8 对（16 张）、停留 0.60 秒；记印登场：翻错留下刚看过那一象 | 记忆广度 + 精度 |

### 阶段新法（大成 / 大圆满）

练到段位多两处「记性上的便利」（`STAGE_RULES` 里不带 `hard`，准备页不给开关，配对判定一个字没动）：

| 段位 | 名 | 做什么 | 为什么是它 |
| --- | --- | --- | --- |
| 大成 | 留影 | 入定照见的那一对不再到 1600ms 就散，留到玩家点下一处才收 | 原来「看一眼就得赶紧背下来」——照见的价值被一个计时器掐头去尾。留影把这段压力去掉，次数照扣，牌仍要一张张点开 |
| 大圆满 | 记印 | 翻错的两处阖上后，牌背留一道极淡的卦象（`cell--ghost`，卦象纹压到三成深） | 记的是玩家**自己刚看过**的那一象。这一门考的是记性，替玩家记一张没翻过的牌等于把玩法删掉；而把「刚看过、只是没记住」的留在盘上，考的仍然是记性 |

**两条都没有多给一次照见。** 照见次数仍是每局 2 次（未入门段 3 次），用一次少一次；
留影改的是「散不散」，记印改的是「阖上之后还剩什么」，都不碰次数、不碰判定。

守卫在 `tests/minigames.test.js`：没到大成照见必须到时就散、大成必须留到点下一处，且次数照扣；
没到大圆满一处残影都不许有；大圆满翻错的那两处必须各留一道，残影的卦象必须等于翻开时看到的那一象，
而且那一处再被点开时残影样式要撤掉。

## 4. 设计依据

### 4.1 与数格辨禁的分工

两者都是「翻开格子获取信息」：

| | 数格辨禁 | 成对翻牌 |
| --- | --- | --- |
| 信息 | 数字（周围禁制数） | 卦象（位置记忆） |
| 推理 | 是（约束传播） | 否（纯记忆） |
| 犯错 | 折心神 | 只白费时间 |
| 盘面 | 6×6 全暗 | 4×3 / 4×4，逐对通开 |

一个靠推、一个靠记，删掉文案也能分辨。

### 4.2 为什么翻错什么都不罚

这一门的定位是「记忆」，不是「容错」。翻错的代价天然存在——你浪费了两次翻牌的时间、
并且暴露了两张牌的信息（对记忆好的人来说反而是收益）。

如果再加惩罚，就会把「记忆游戏」变成「谨慎游戏」，玩家会不敢翻。

### 4.3 为什么盘面随对数放大

对数是最直观的难度旋钮：5 对（10 张）与 8 对（16 张）在短时记忆上的差别极大。
所以这一门允许 `pairs` 从 5 到 8，盘面行数随之变化（列固定 4）。

### 4.4 被否决的方案

这些是我否掉的路，留下来是因为它们划出了这门功法的边界——每一行都写着当时的诱因：

| 方案 | 为什么否掉 |
| --- | --- |
| 翻错扣时间 | 见 §4.2 |
| 盘面固定 12 张 | 对数无法成为难度旋钮，只能靠收紧时限 |
| 卦象用汉字 | 盘面不写汉字 |
| S 只看时间 | 「快但乱翻」会拿 S，与「记」的定位冲突 |
| 无提示 | 天阶功法门槛高，新手第一次接触 8 对会直接崩；入定是合理出口 |

## 5. 界面与反馈

原文未设独立的「界面与反馈」节，以下五项由原文 §1 / §2 / §3 / 待验的信息归拢，不新增数字。
判据只有一句：**这一手做对了，盘面上该看见什么。**

| 项 | 落点 |
| --- | --- |
| 判据 | 连翻两张同卦象 → 这一对永久通开（牌面不再阖上）；翻错 → 两张阖上，多记翻牌、白费时间 |
| 代价 | 惩罚只有一种：慢——多记两次翻牌 + 白费时间；时限到还没全通 → 失败 F；照见一对也要花次数（用一次少一次） |
| 操作 | 点击翻牌；入定照见一对（直接把两张亮出来，未入门段 3 次、其余 2 次） |
| 进度 | 局内 HUD 只报「下一条线还差多少」；双条件时这一句怎么把时间线与翻牌线都报清楚，见 §7 |
| 收束 | 全部对子通开即结算；时限到还剩对子 → 失败 F |

## 7. 待验

- **S 的双条件在界面上怎么表达**：局内 HUD 只报「下一条线还差多少」，双条件时玩家可能只知道时间那一条。
- 卦象图案（8 个）是否一眼分得清——尤其同心圆类的几个。
- 天阶门槛高，多数玩家前期见不到；难度曲线缺少真实样本。
- 8 对（16 张）在 4.7 寸屏的格数与视觉密度，落在圆满段，见 [圆满](04-圆满.md) §6；本文件不重复。
