# 需求（Spec）· 小成（第三段 · 第 51–200 关）

> 目标还是 256，起手块从 2 增到 3。

我想证明一件事：空间本身就是旋钮。4×4 上多占一格，前几步能走的路立刻少一截，你得更早决定把大块留在哪个角。抬目标只是更长的重复，多占一格才是真的变紧。

## 1. 参数与规格

| 项 | 第 51 关（段首） | 第 200 关（段界） |
| --- | --- | --- |
| 盘面 | 4×4 | 4×4（整段不变） |
| 目标块 | 256 | 256（整段不变） |
| 起手块 | 3 | 3（整段不变） |
| fourRate（起手给 4 的概率） | 0.350 | 0.300 |
| S | 合出 256 | 合出 256 |
| A | 128 | 128 |
| B | 64 | 64 |
| C | 没到 64 | 没到 64 |

这是「五段参数」里第三行（目标 256 / 起手 3）的展开：目标与上一段相同，
唯一的新东西是起手块 +1——4×4 上多占一格，可用空间更少，更容易被堵死。

## 2. 盘面介绍

- 开局 3 块同时落地、整盘亮一下；空格比上一段少一个，凹槽里能看出剩下的余地更紧。
- 牌面底色、金边、合并弹、补块弹的反馈与上一段一致。
- HUD 仍是「最大 X / 256」，但开局那三块已经占掉了更多格子，
  「把大块留在一角」这条策略（见总览 §5）从这里才真正开始吃紧。

## 3. 评级与判定

| 关 | S | A | B | C | F |
| --- | --- | --- | --- | --- | --- |
| 51 | 合出 256 | 128 | 64 | 没到 64 | 盘满且相邻无同数 |
| 200 | 合出 256 | 128 | 64 | 没到 64 | 同上 |

评级线与上一段完全相同（目标没变），难度全压在起手空间与 fourRate 上：
第 51 关 fourRate 0.350 → 第 200 关 0.300。盘满推不动依旧是 F。

## 4. 设计意图

我这一段教的是「目标不变也能更难」。前两段靠抬目标制造变化，这一段证明空间本身就是旋钮：
3 块起手让开局可用空间更少，玩家必须更早决定把大块留在哪个角，
否则在多一格占用下更容易走进盘满无同数的死局。

## 5. 常见失误

- **第 51 关**：起手从 2 块变 3 块，沿用上一段「先随便推几手再说」的玩家会发现空地不够用了。
- **第 120 关前后**：fourRate 收到约 0.327（据 `tweakParams` 折算），开局更少给 4，
  凑同数的步数需求上升，盘满的风险跟着上来。
- **第 200 关（段界）**：fourRate 落到 0.300，目标仍 256，但 3 块起手的挤压感已到本段顶点。
