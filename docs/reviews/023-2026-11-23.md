## 待你拍板

这三项是**真 SDD 欠账**，本轮没动，因为改它们要动本体并要你认领：

1. **规格没有显式验收标准 / 稳定 ID**。`spec/00-契约/` 六篇是「契约 + 守卫」的短句，能测但没写成可逐条引用的 AC；29 个场景 ID 只存在于 `docs/reviews/10-规格覆盖.md`，S 本体里没有。补齐要重出三份 R，且 ID 必须机器可比对，否则就是假追溯。
2. **任务层不是 Spec Kit 式的任务清单**。`tasks/` 现在是测试映射 / 实现映射 / 台账，能回答「落到哪」，但不能回答「下一步做哪一项、依赖谁、跑哪条命令验」。要不要把它改成有序原子任务表，要你定。
3. **三个点头位没有留痕**。`OVERVIEW.md` 第四节列了规格认领、盲区接受、差异裁定，但认领结论只在对话里，没有写进版本化记录。SDD 的 review gate 要「谁、何时、认了哪一版」可查。

另：`game.test.js:795` 晋段日志顺序的偶发红与 `tasks/05` C8 的灵种落底偶发红仍未修，属测试底座稳定性欠账，不因本轮静态全绿而消失。
