## 二、覆盖清单

这条 bug 的性质：`diffLines = ['……段名就是「这门练到哪」——', + '它同时也是……']`。第一个字符串末尾的逗号把它封成一个数组元素，第二个元素以一元 `+` 开头（`+ '字符串'` → `NaN`）。WXML 用 `wx:for="{{item.lines}}"` + `{{line}}` 直接渲染，于是所有功法的说明页「段位·关卡·耗气」节都会显示一行「NaN」，而那句解释「段位就是这门功法的级」整句丢失。现有测试虽调了 `practiceTopic`，但没有一条检查 lines 的内容。

| 检查面 | 结果 |
| --- | --- |
| 玩家可见路径 | `help.wxml` 的 `{{line}}` 直出，确认真会显示 NaN，不是内部值 |
| 影响面 | `practiceTopic` 对所有功法与冲关局都生成 `diffLines`，全门说明页受影响，非单门 |
| 信息完整性 | 正向断言钉住那句规则必须在，不许靠删行掩盖 |
| 测试盲区 | 原 108 条里没有一条查 lines 是否含空值，新断言补上这个面 |
