## 二、覆盖清单

这条 bug 的性质：`goalText()` 自带进度（`连锁 0/5 次`），`match.js` 又在其前面拼 `GOAL_NAMES[goalType]`（`连锁`），JS 层就成了「连锁 连锁」；普通 HUD 的 WXML 再拼一次 `value / max`，最终读成「目标 连锁 连锁 0/5 次 0 / 5」。其余五门（blocks / click / link / memory / seal）的 meter.label 都是纯文字，只有这一门破了约定。

| 检查面 | 结果 |
| --- | --- |
| 全局 label 约定 | 六门 meter 全带 value/max；五门 label 纯文字，三秀已归队 |
| 玩法结构 | 目标种类、计数口径（按「次」）、评级线一字未改 |
| 规则信息 | 「需连锁 3 层」「收灵草」等细节仍在 `vm.hint`，无丢失 |
| 两处 HUD | 只改 label 源头，两处渲染（普通 HUD 拼 value/max、游戏 HUD 只显示 label）都不动，与其他门一致 |
