# 阵法·九宫补缺诀 → 九宫填数（总）

> 九宫盘上留着空格，每行、每列、每宫都要把 1 到 N 各填一遍。填错一格记十秒，时辰到还没填完即完成。
>
> 五段六篇：本篇放五段共用的骨架（盘面 / 规则 / 依据 / 界面 / 代码），
> 每段的规格、挖洞、时限与评级线写在各段文档里，两边不互相抄。

- 功法：阵法·九宫补缺诀（黄阶，qiSave −9%）｜玩法 id：`shudu`｜无阶段新法
  （原文头部口径：不动判定、准备页不给开关；§3.1 两处「看得更清」照原样保留，见该节说明）
- 时长基准 `base = 38`

**这组文档怎么读**：本文件只写「五段共用」的东西。每一段的规格与手感各有一篇，数字都在那里：

## 1. 盘面骨架（五段共用）

方格盘，规格按段：4×4 → 6×6 → 9×9。

- 4×4 是 2×2 宫，6×6 是 2×3 宫，9×9 是 3×3 宫；
- 挖掉的格子数按段递增（8 → 46）；
- 数字直接显示（这一门不换图案，数字本身就是内容）。

盘面规格只在换段时变；段内不变。

## 2. 规则骨架（五段共用）

| 项 | 规则 |
| --- | --- |
| 目标 | 每行、每列、每宫各填一遍 1…N |
| 完成 | 填满且全对 |
| 填错 | 罚 **10 秒**（数落错了地方，得回头改） |
| 未完成 | 时辰到还没填完 → **失败 F** |
| 挖洞 | 生成时逐格验证「解仍唯一」，否则重挖 |

**「解唯一」是硬要求**：如果有多个解，玩家填出一个合法解却被告知错，那是设计缺陷而不是难度。

### 2.1 三段式操作（原文 §3）

- 点格子 → 选中
- 点数字键 → 落子
- 点 `✕` → 清空该格

三段式操作，与落石 / 滑格的「方向键」区分开。

### 2.2 时限给得比 B 线宽一截

以 9×9 为例，420 秒 vs B 线 330–410 秒：是为了让「填完但慢」还有个 C，
而不是一超线就直接判负——**没填完（F）和填得慢（C）是两件事**（原文 §4 表后说明）。

## 3. 五段怎么变

每一段换的是**盘面规格（复杂度）**，不是秒表：

| 段 | 这一段新学的一件事 | 主轴 |
| --- | --- | --- |
| 一 · 未入门 | 4×4 / 2×2 宫：看懂「行、列、宫各一遍」 | 复杂度（规格） |
| 二 · 入门 | 6×6 / 2×3 宫：换宫格形状 | 复杂度（规格） |
| 三 · 小成 | 9×9 / 3×3 宫：正经数独；挖洞升到 32 | 复杂度（规格） |
| 四 · 大成 | 仍是 9×9、挖洞 40；解锁「密勘」标唯一空位 | 挖洞 + 看得更清 |
| 五 · 圆满 | 仍是 9×9、挖洞 46；解锁「唯余」描金 | 挖洞 + 看得更清 |

### 3.1 阶段新法（大成 / 大圆满）

练到段位会加两处「看得更清」，都不动判定（`STAGE_RULES` 里不带 `hard`，所以准备页不给开关）：

| 段位 | 名 | 做什么 | 为什么是它 |
| --- | --- | --- | --- |
| 大成 | 密勘 | 某行 / 列 / 宫只剩一个空位时，那一格描一圈（`cell--sole`） | 9×9 盘上「哪一行还差一格」要靠眼睛扫整盘；标出来省的是扫视，不是推理——填几仍要自己算 |
| 大圆满 | 唯余 | 选中空格时，同行列宫排除后只剩一个数，那个键描金（`pad__key--only`） | 把唯余法那一步省下来。前面已经承认「压暗到只剩一个亮着等于摆出唯余」，这一条只是把同一件事说到明处 |

两条都**不替你填**：填错照样罚 10 秒，藏起来的答案一个都没漏。密勘只标位置、唯余只标「只能填它」，
从「知道填哪个」到「点下去填对」之间仍然是玩家的事。

守卫在 `tests/minigames.test.js`：未到大成一处都不许标；大成的每一处都必须是「行列宫只剩一个空位」，
反过来凡是唯一空位也都得标；唯余只在候选恰好剩一个时描，且描的必须是那一个。

> 口径说明：原文头部写「无阶段新法」，而 §5.6 又列出这两处加成。本文两处照抄、不改原文措辞：
> 头部「无阶段新法」按「不动判定、没有 `hard` 开关」理解；这两条是「看得更清」的便利，不是难度新法。
> 有疑义见 §7 与文末汇报。

大成、圆满两段的具体体现分别见 [大成](03-大成.md) §2 / [圆满](04-圆满.md) §2。

## 4. 设计依据

### 4.1 为什么是规格递进而不是收紧时间

4×4 先把「行、列、宫各一遍」这个规则看懂；6×6 换宫格形状（2×3）；9×9 才是正经数独。

如果只在 4×4 上收紧时间，玩家永远学不会 9×9 的宫格约束——**规则理解需要盘面来教**。

### 4.2 与阵灯推演的分工

| | 阵灯推演 | 九宫填数 |
| --- | --- | --- |
| 改状态 | 点一格改一片（联动） | 填一格只改一格（无联动） |
| 比什么 | 省步数（想得久不扣） | 快（含罚时） |
| 失败 | 阵溃（预算耗尽） | 时辰到没填完 |

一个是「联动推演」，一个是「静态约束求解」。

### 4.3 填错罚 10 秒而不是判负

数独的错通常是「这一格填 5 但接下来推不下去」。如果直接判负，玩家会极度谨慎，一局打得极慢。

罚 10 秒的语义是「回头改」，允许试错，但试错要付时间。10 秒约等于「两三次犹豫」。

### 4.4 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 允许非唯一解 | 玩家填对却说错，是设计缺陷 |
| 填错即判负 | 见 §4.3 |
| 只有 9×9 | 4×4 / 6×6 是教规则的台阶 |
| 用图案代替数字 | 数独的内容就是数字，换图案等于换玩法 |
| 时限只给到 B 线 | 「填完但慢」会无处落脚，只能判 F |

## 5. 界面与反馈（五项逐门过）

原文 §5.5「界面与反馈」整节搬入：

| 项 | 落点 |
| --- | --- |
| 难度 | 主承重轴是**复杂度（规格）**：4×4 → 6×6 → 9×9、挖洞 8 → 46、时限 150 → 420 秒。9×9 的三段（困难 / 极难 / 绝境）只靠挖洞 32 / 40 / 46 区分，边际最小——这是这一门唯一偏弱的地方，照实写在这里。 |
| 显示 | 选中格 `cell--sel`；同行 / 同列 / 同宫的空格 `cell--peer` 浅底；**数字键把同行列宫已经出现的数压暗**（`pad__key--seen`）；填错的格 `cell--bad`；HUD 给「已填 X / N」与含罚时的用时。 |
| 特效 | **做对一手不动。** 数独的反馈就是「数字落下去，此外什么都没发生」——加弹跳、加粒子、加金圈，都是在替玩家确认一个他自己已经推出来的结论。只有填错才有浮字与 `cell--bad`：错了必须说得清。 |
| 引导 | goal 一句 + 四步 + 三个词条（宫 / 题面格 / ✕ 清除）+ 一行 inline；tip 教「先找唯一候选」。首局有入门卡。 |
| 关卡 | 段内按 `timeLimit` 收紧；盘面规格只在换段时变，`levelDelta` 报时限。`timeLimit` 是整秒，但 `duration` 一起收，所以 **1000 关里 429 关真的变了**——是十五门里最密的一门。 |

**v9 口径修正**：原文写「段内 40 关按 `timeLimit` 收紧」，其中「段内 40 关」是 v8 旧口径；
v9 五段关数为 10 / 40 / 150 / 300 / 500，段内收紧按 v9 关号段理解。
「1000 关里 429 关真的变了——是十五门里最密的一门」是原文实测值，照抄不改。

### 5.1 数字键压暗：这一门最重要的一处可读性

**数字键压暗是这次补的，也是这一门最重要的一处可读性。** 要做的决策只有一句「这一格能不能填 5」，
依据全在同行列宫的格子里；不标出来，每填一格都要用眼睛扫二十几格——那不是难度，是眼力。

压暗**不是禁用**：点下去照样落子，填错照样罚 10 秒，规则一个字没改。代价也说清楚：
候选里只剩一个亮着时，等于把「唯余法」直接摆出来。这是有意接受的——这一门是黄阶入门功课，
教的是数独规则，不是竞赛推理。

### 5.2 「点了没反应」必须说话

**「点了没反应」必须说话。** 点题面格、没选格就按数字，原来都写进 `vm.status`——
而 HUD 那行取的是 `goal || status`，goal 一直有值，这两句从来没露过面。现在走浮字：
`这一格是题面，改不得` / `先点一格空格，再点下面的数字`。同一个坑在循数勘禁诀的 chord 上也踩过。

## 7. 全门待验

以下为全门性 / 跨段待验；9×9 与挖洞相关的条目按段下到段篇，本文件不重复。

- 420 秒（7 分钟）一局是否超出「碎片时间」的定位——这是全站最长的一局，与「30–90 秒」的主力区间差距很大。
- 压暗键与正常键在强光下的区分度：`--jade-dim` 与 `--jade` 差得够不够一眼（这两个色在落石盘面里靠「凸 / 凹」区分，这里是纯明度差）。

段相关待验的落点：9×9 点格 + 数字键操作速度、数字键区挤压盘面 → [小成](02-小成.md) §6；
密勘描圈抢眼 → [大成](03-大成.md) §6；挖洞 46 纯推理可解性、压暗摆出唯余后圆满是否太轻、唯余描金抢眼 → [圆满](04-圆满.md) §6。
