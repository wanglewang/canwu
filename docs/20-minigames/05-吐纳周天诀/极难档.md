# 极难档（第四章 · 121–160 关）

> 带 20rpx、一拍 1.44 秒、单侧 140ms。要盯带的内沿——盯带心已经太迟了。

## 1. 盘面

| 项 | 值 |
| --- | --- |
| 息数 | 10（章内不变） |
| 带粗 | 20rpx → 14rpx（章末） |
| 单侧判定窗 | ±140ms → ±101ms（第 158 关触底） |
| 收一步 | 0.0286 / tick |
| 光环到带外沿 | 906ms |
| 点中后余程 | 391ms |
| 拍长 | 1439ms |
| 整局 | 14.4s |

**带占行程 19.7%，不到五分之一**。10 拍、1.44 秒一拍，玩家已经没有「读完一圈再点」的余地，
只能靠前几拍建立的节律接着走。余程 391ms，点完之后还有小半拍的空档。

**章末 14rpx 是全门最细的带**，比绝境档的 16rpx 还细。这不是画错：下限是按**毫秒**定的（单侧 100ms），
`speed` 越慢的档，同样 100ms 折成 scale 越小，带子自然越窄。极难档 step 0.0286 比绝境 0.0319 慢，
所以它的 100ms 只有 14rpx。第 158 关触底，158–160 三关不再变。

## 2. 规则

- **判定**：单侧 ±140ms（总窗 280ms）。早 2.2 倍、晚 1.4 倍不变。
- **评级**：满分 10 分。S = 9、A = 7.5、B = 5。
- **容错**：到 S 可丢 1 分（10.0%）；到 A 可丢 2.5 分（25.0%）；到 B 可丢 5 分（50.0%）。
- **一局**：10 拍，约 14.4 秒。

偶数拍数下 B 又回到 50%：`ceil(10 × 0.5) = 5` 正好卡在 `aMin − 1 = 6.5` 之下，取 min 后是 5。
所以 B 的宽窄是拍数奇偶的副产品，不是刻意分档。

## 3. 这一档在教什么

教**盯内沿**。单侧 140ms 时，如果还按「环到带正中就点」，手指落下时环已经往外走了一截——
必须把注意力放在带的**内沿**（环刚碰到就动手），让触控延迟把这几十毫秒自然补掉。

10 拍也是全门第一个「两位数拍数」，数拍的人容易在第七八拍乱掉。这一档的失败大多不是点不准，而是**数丢了**。

## 4. 会在哪掉档

- 掉到 A：丢 1.5 分以上。
- 掉到 B：丢 2.5 分以上。
- 掉到 C：丢 5 分以上（正好一半）。

## 5. 待验

- **14rpx 在真机上还分不分得清内外沿**——这是全门最细的一档，分不清就等于「猜」，与节律题的本意相反。
  若确实看不清，宁可把下限抬到 120ms（带粗回到 17rpx），也不要让玩家对着一条 14rpx 的线赌。
- 140ms 是否已经贴近「人能在 40ms 刷新下分辨」的边缘：带半宽 0.102 scale，环每帧走 0.0286，
  一帧占掉带宽的 28%——留给眼睛确认的只有三帧半。
- 章末触底后连着 3 关报「与上一关规格相同」，加上下一章换档回升到 115ms，玩家会不会觉得「第四章末尾白打了」。
