# 简单档（第一章 · 1–40 关）

> 带 30rpx、一拍 2.18 秒。这一档只教一件事：光环落进朱带的那一瞬该按下去了。

## 1. 盘面

| 项 | 值 |
| --- | --- |
| 息数 | 7（章内不变） |
| 带粗 | 30rpx → 22rpx（章末） |
| 单侧判定窗 | ±322ms → ±227ms |
| 收一步 | 0.0189 / tick |
| 光环到带外沿 | 1261ms |
| 点中后余程 | 592ms |
| 拍长 | 2178ms |
| 整局 | 15.2s |

**带子占光环收敛全程近三成**（1.75 → 0.72 的 1.03 行程里占 0.307），宽到不用瞄。
光环从起点慢悠悠走到带前要 1.26 秒，玩家有足够时间把「快到了」认出来。

章内带粗从 30rpx 收到 22rpx：收窄了四分之一，但仍然是一段明显的区间，不会变成线。
其余六项全部不动——这一档不缩盘、不缩拍、不加拍。

## 2. 规则

- **判定**：单侧 ±322ms（总窗 644ms）。早半拍窗 2.2 倍、晚半拍窗 1.4 倍。
- **评级**：满分 7 分。S = 6、A = 4.5、B = 3.5，全走完但低于 B 记 C。
- **容错**：到 S 可丢 1 分（14.3%），也就是**顶格允许一个空拍，或两个合拍**；
  到 A 可丢 2.5 分（35.7%）；到 B 可丢 3.5 分（50.0%）。
- **一局**：7 拍，约 15.2 秒。比一次呼吸长一点，是全站最短的一局。

## 3. 这一档在教什么

教「看见环进带就点」这一件事，别的都不考：带子宽到点偏了也算圆满，7 拍里错 1 分仍是 S。
判定窗 322ms 比一次触控抖动还宽，**这一档不存在「手滑」**——掉档只有一种方式，就是连着两拍没跟上。

S 的 1 分容错占 14.3%，是五档里最宽的相对容错；这也是「绝对容错 1 分」在最少拍数上的必然结果。
玩家在这里学的是节拍感，不是精度。

## 4. 会在哪掉档

- 掉到 A：丢 1.5 分以上（1 空拍 + 1 合拍，或 3 个合拍）。
- 掉到 B：丢 2.5 分以上。
- 掉到 C：丢 3.5 分以上——7 拍里错掉一半，基本是整局没进入节律。

## 5. 待验

- 单侧 322ms 是否过宽：点哪儿都算圆满，会不会削弱「找那一瞬」的手感（这一条要真机试，不是算得出来的）。
- 带 30rpx 叠在光环上，两者的边界会不会糊成一片（光环是实心的，带是半透明叠加）。
- 40 关只收 118ms（322 → 227），玩家能不能感到「这一章在变紧」；若完全无感，考虑把章节台阶挪到带色或拍声上，而不是继续压毫秒。
