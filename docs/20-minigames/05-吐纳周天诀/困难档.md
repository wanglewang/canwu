# 困难档（第三章 · 81–120 关）

> 带 22rpx、一拍 1.62 秒、单侧 178ms。窗已经落到反应时间以下：不能再「看见再点」。

## 1. 盘面

| 项 | 值 |
| --- | --- |
| 息数 | 9（章内不变） |
| 带粗 | 22rpx → 16rpx（章末） |
| 单侧判定窗 | ±178ms → ±126ms |
| 收一步 | 0.0254 / tick |
| 光环到带外沿 | 1002ms |
| 点中后余程 | 441ms |
| 拍长 | 1624ms |
| 整局 | 14.6s |

**带占行程 22.2%，第一次「像条线而不像段区间」**。光环到带前只剩 1 秒整，玩家的眼睛要在环还没到之前
就开始数拍。章末收到 16rpx、单侧 126ms（仍未触底，本章最低 126ms）。

## 2. 规则

- **判定**：单侧 ±178ms（总窗 356ms）。早 2.2 倍、晚 1.4 倍不变。
- **评级**：满分 9 分。S = 8、A = 6.5、B = 5。
- **容错**：到 S 可丢 1 分（11.1%）；到 A 可丢 2.5 分（27.8%）；到 B 可丢 4 分（44.4%）。
- **一局**：9 拍，约 14.6 秒。

B 线的相对余量从普通档的 50.0% 掉到 44.4%：不是刻意压，而是 `ceil(9 × 0.5) = 5` 撞上了
`aMin − 1 = 5.5` 之后取整的结果——9 拍这种奇数拍数天然让 B 窄一点。

## 3. 这一档在教什么

教**预判接拍**。181ms 是「看见再点」的极限，178ms 已经越过它：等环进了带再动手，手指落下去时环已经偏出。
玩家必须在前一拍结束时就知道下一拍什么时候到——这正是「固定网格」这条改动的兑现处。

从这一档起，**能不能打下去不取决于手速，取决于有没有把拍子记住**。反应快的人在这里没有优势。

## 4. 会在哪掉档

- 掉到 A：丢 1.5 分以上（三次合拍或一空一半）。
- 掉到 B：丢 2.5 分以上。
- 掉到 C：丢 4 分以上。

## 5. 待验

- 章内从 178ms 收到 126ms（−29%），一步 29% 的收紧会不会让第 120 关比第 81 关明显难一档，而不是「同一档更紧」。
- 16rpx 的带在真机上是否还看得清内外沿；看不清就变成「凭感觉点」，与「节律」的意图相反。
- 178ms 与普通档 231ms 只差 23%，但一个是「看得见再点」、一个是「必须预判」——玩家会不会觉得第三章像换了玩法，而不是变难。
