# 绝境档（第五章 · 161–200 关）

> 带 18rpx、一拍 1.29 秒、单侧 115ms。眼睛已经跟不上，得靠身体记住拍子。

## 1. 盘面

| 项 | 值 |
| --- | --- |
| 息数 | 11（章内不变） |
| 带粗 | 18rpx → 16rpx（第 174 关起不再变） |
| 单侧判定窗 | ±115ms → ±102ms（第 174 关触底） |
| 收一步 | 0.0319 / tick |
| 光环到带外沿 | 826ms |
| 点中后余程 | 351ms |
| 拍长 | 1291ms |
| 整局 | 14.2s |

**带占行程 17.8%**，一圈里不到五分之一是能点的时间；光环从起点到带前只剩 0.83 秒。
余程 351ms 是全门最短——点中之后几乎立刻换拍，盘面从「看着环走」变成「贴着环走」。

章内只从 115ms 收到 102ms（−11%），**第 174 关就撞上 200ms 总窗的硬下限**，此后 26 关
（175–200）参数与判定带一起不动、带粗停在 16rpx。这一档的章内变化远小于其它四档，
因为它的起点已经贴着底线了。

## 2. 规则

- **判定**：单侧 ±115ms（总窗 230ms），约等于刷新率的三帧。早 2.2 倍、晚 1.4 倍不变。
- **评级**：满分 11 分。S = 10、A = 8.5、B = 6。
- **容错**：到 S 可丢 1 分（9.1%）；到 A 可丢 2.5 分（22.7%）；到 B 可丢 5 分（45.5%）。
- **一局**：11 拍，约 14.2 秒。

S 的 1 分只占 9.1%：11 拍要拿 10 分，**全局只有 1 次空拍或 2 次合拍的余地**。
这是全门最紧的相对容错，而它仍然是「绝对 1 分」——同一条规则在最多拍数上自然最严。

## 3. 这一档在教什么

教**不看也算得准**。115ms 只有三帧，等眼睛确认「进带了」再动手已经晚了两次；这一档能过的人，
是在前三四拍里把拍长（1291ms）记进身体，后面靠节奏感按下去的。

它也是唯一一档「章内几乎没有变化」的：起点已贴下限，第 174 关之后 26 关盘面完全一样。
好处是稳定——熟练的人可以一直刷同一套节奏；坏处是这 26 关在界面上没有任何新东西。

## 4. 会在哪掉档

- 掉到 A：丢 1.5 分以上（三次合拍就没了）。
- 掉到 B：丢 2.5 分以上。
- 掉到 C：丢 5 分以上。

## 5. 待验

- **±102ms 与触控延迟的实际关系**：这是全站最窄的判定窗，若某类机型触控上报延迟超过 50ms，这一档就变成碰运气。
- 175–200 共 26 关报「与上一关规格相同（本章第 k / 40 关）」，玩家会不会以为关卡坏了（产品判断，见 `04-open-issues.md` D9）。
- 从点中到换拍 351ms 的空档，会不会让人觉得「空了一拍」从而提前按下一拍。
- 11 拍是不是太多：数拍的人到第八九拍容易乱，而这一档的失败大多来自「数丢了」而不是「点不准」——若是这样，问题在拍数而不在窗宽，该考虑把 11 拍收回 10 拍、把这部分难度放回盘面。
