# 普通档（第二章 · 41–80 关）

> 带 26rpx、一拍 1.84 秒。节奏第一次真的在催，但还来得及「看见再点」。

## 1. 盘面

| 项 | 值 |
| --- | --- |
| 息数 | 8（章内不变） |
| 带粗 | 26rpx → 18rpx（章末） |
| 单侧判定窗 | ±231ms → ±163ms |
| 收一步 | 0.0224 / tick |
| 光环到带外沿 | 1108ms |
| 点中后余程 | 501ms |
| 拍长 | 1843ms |
| 整局 | 14.7s |

比简单档多一拍、环快 18%，带子细 4rpx。**带占行程 25.3%**——仍然是一段区间，
但已经不像简单档那样「怎么点都中」。光环到带前的时间从 1.26 秒压到 1.11 秒。

章内带粗收到 18rpx、单侧窗收到 163ms（仍远高于 100ms 下限，本章不会触底）。
息数、拍长、余程全章不变。

## 2. 规则

- **判定**：单侧 ±231ms（总窗 462ms），约等于人的平均反应时间。早 2.2 倍、晚 1.4 倍不变。
- **评级**：满分 8 分。S = 7、A = 5.5、B = 4。
- **容错**：到 S 可丢 1 分（12.5%）；到 A 可丢 2.5 分（31.3%）；到 B 可丢 4 分（50.0%）。
- **一局**：8 拍，约 14.7 秒。

绝对容错与简单档完全一样（S 都是 1 分、A 都是 2.5 分），但分母大了：同样一次空拍，
在 7 拍里是 14.3% 的余量，在 8 拍里只剩 12.5%。**这一档开始「同样的失误要算账」**。

## 3. 这一档在教什么

教「按拍数呼吸」：8 拍比 7 拍多一拍，玩家得在局内维持住节律，而不是数到七就松手。
单侧 231ms 刚好卡在「看见再点也来得及」的上限——这是**最后一个可以纯靠眼睛走完的档位**。

困难档的 181ms 落到反应时间以下，从那里开始必须预判。所以普通 → 困难这一跳不只是 23% 的窗宽，
而是换了一种能力：从「看」换成「接」。

## 4. 会在哪掉档

- 掉到 A：丢 1.5 分以上。
- 掉到 B：丢 2.5 分以上。
- 掉到 C：丢 4 分以上（一半的拍数）。

## 5. 待验

- 普通 → 困难是不是「突然要预判」：档差只有 23%，但跨越了 200ms 这条心理线，玩家可能觉得是断层而不是过渡。
- 带 26rpx 与 18rpx 在同一章内出现，两种粗细在真机上能不能明显区分（若不能，这一章等于没有变化）。
- 8 拍与 7 拍的差别玩家能不能察觉：若察觉不到，第二档的「多一拍」只体现在时长上，等于白送。
