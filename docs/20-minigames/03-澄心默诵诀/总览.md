## 1. 盘面骨架（五段共用）

3×3 = 9 格。每轮从 2 格起，随轮次增长。

- 口诀按序在格子上闪一下（`flashMs`），间隔 `gapMs`；
- 闪的时候**不显示序号**——旧版把序号写在格子上，等于直接给答案，已修掉；
- 盘面不写汉字，用图案（`emblem`）区分位置。

## 2. 规则骨架（五段共用）

| 项 | 规则 |
| --- | --- |
| 复述 | 按原序点回这一轮的格子 |
| 时限 | 题长 × 每字息数（`msPerNote`）+ 起手半息 |
| 点错 | 罚 **1.5 息**、连对清零；**不立即失败** |
| 整轮记岔 | 折 **1 盏心神**（共 3 盏），进入下一轮 |
| 心神耗尽 | 失败 F |
| 结束 | 时辰到（失败）或轮数打满 |

**点错不致命**是这一门的关键：乱试会把时间试完，时间见底才折心神。玩家有「试」的余地，但试的代价是时间。

### 2.1 两条路：稳与赌

**稳**：一轮不失误，连对每多一轮 **+15%** 分，封顶 **+45%**。失误清零。

**赌：抢记**——闪烁过程中**长按盘面**可以抢先开口，跳过还没闪的部分：

| 抢得越早 | 倍率越高 |
| --- | --- |
| 还剩很多字没闪 | ×1.9（最多） |
| 快闪完了 | ×1.2 |

**一个字都没闪时不许抢**——否则误按长按直接送命。

这条设计让「记忆」不是纯天赋：记性好的人稳稳拿满，记性一般的人可以赌「少看两个也能记住」。

### 2.2 得分与评级

```
每轮得分 = 10 × 题长 × 连对加成 × 抢记倍率
```

评级按总分，五段 S/A/B 线：

| 段 | S | A | B |
| --- | --- | --- | --- |
| 一 · 未入门 | ≥273 | ≥175 | ≥91 |
| 二 · 入门 | ≥363 | ≥233 | ≥121 |
| 三 · 小成 | ≥465 | ≥298 | ≥155 |
| 四 · 大成 | ≥567 | ≥364 | ≥189 |
| 五 · 圆满 | ≥636 | ≥408 | ≥212 |

各段评级线同时写在对应段篇 §3；原文只给分数门槛，未给「丢几分掉段」的分解，不推算。
失败态只有一种：心神耗尽失败 F（时辰到也算失败）；轮数打满即正常收束。

### 2.3 阶段新法（两条都是「改规则」）

| 段位 | 名 | 规则 | 可关 |
| --- | --- | --- | --- |
| 大成 | 逆诵 | 第 3 轮起，**奇轮要从未字往前点回** | 是 |
| 圆满 | 叠印 | 第 5 轮起，口诀里会出现**重复的格子**（同一格要连点两下） | 是 |

两条都是「改规则」，所以准备页给开关。想安心练基础记忆的人可以关掉——这是「阶段新法要加规则」的必要配套：加规则可以，但不能强制（见 `02-design-principles.md` 第十一条）。

## 4. 设计依据

### 4.1 为什么点错不立即失败

记忆类玩法最挫败的瞬间是「记错一个字，整轮作废」。所以这一门的失败单位是**轮**，不是**字**：点错罚时间，整轮记岔才折一盏心神。

代价转移：从「一次失误 = 失败」变成「一次失误 = 时间损失」，玩家仍然紧张，但不会一错就崩。

### 4.2 为什么要有抢记

纯记序玩法只有一条曲线：记性好的永远满，记性差的永远不满。抢记给了第二条曲线——**你自己决定赌多少**。这让「记忆」变成一个有策略的动作。

### 4.3 为什么抢记最多 ×1.9 而不是更高

如果抢记收益远高于稳打，所有人都会在第二字之后抢，那就没有「稳」这条路了。×1.9 的落点让「记得住就赚，记不住就亏」大致平衡。

### 4.4 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 闪的时候在格子上写序号 | 等于直接给答案（旧版 bug，已修） |
| 点错即失败 | 一次失误就崩，记忆类玩法最挫败的形态 |
| 抢记无上限 | 会压过稳打 |
| 一个字没闪也能抢 | 误按长按直接送命 |
| 逆诵强制不可关 | 改规则的阶段新法必须可关（见 `02-design-principles.md` 第十一条） |

## 5. 界面与反馈

原文没有独立的「界面与反馈」节，按五项逐门过（数字均来自原文）：

1. **判据**：口诀按序在格上闪，不显示序号、用图案区分位置；按原序点回即对。
2. **代价**：点错罚 1.5 息、连对清零但不立即失败；整轮记岔折 1 盏心神（共 3）；心神耗尽失败 F。
3. **操作**：点击复述为常规手势；闪烁中长按盘面即抢记（两者同一盘面，见 §7 误触待验）。
4. **进度**：最大轮数 6→9（段篇展开）；连对加成每轮 +15%、封顶 +45%，失误清零。
5. **收束**：时辰到（失败）或轮数打满；命中的失败态只有失败 F，没有别的即时失败。
