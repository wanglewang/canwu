# 小成（第3段 · 第 51–200 关）

> 轮数加到 8、闪速提到 0.49 秒：盘面仍固定 3×3，靠规模与速度加压，记忆链要撑得更长。

## 2. 盘上长什么样

- 3×3 盘，口诀按序闪 0.49 秒、间隔 0.23 秒；每轮从 2 格起、随轮次增长，最多 8 轮。
- 闪时不显示序号、盘面不写汉字，用图案区分位置。
- 每字限时 0.42 秒，整轮时限 = 题长 × 0.42 秒 + 起手半息。

## 4. 这一段在教什么

把规模与速度同时再推一档（7→8 轮、0.56→0.49 秒、限时 0.48→0.42 秒），让玩家在没有新规则的情况下，靠「稳」或「赌」自己的策略去撑一条更长的链。抢记（赌）在此段开始比前两段更有价值——少看两个字的收益要自己权衡（依据见总览 §4.2）。

## 5. 会在哪掉段

原文未逐关记录失误点，以下按本段机制据实列出：

- 第 51 关起：8 轮里后段题长更大，整轮记岔折心神的概率上升。
- 闪速 0.49 秒、间隔 0.23 秒：看漏字后点错 → 罚 1.5 息、连对清零。
- 心神三盏耗尽 → 失败 F。
