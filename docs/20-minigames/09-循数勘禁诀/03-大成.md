# 大成（第四段 · 第 201–500 关）

> 盘换到 8×8（64 格、10 禁制），**心神从 3 盏降到 2 盏**——容错第一次收紧。同时「勘位」登场：
> 开局勘出 3 处禁位并标出，是纯便利，不改规则。

## 1. 这一段（300 关）的盘

| 项 | 第 201 关（段首） | 第 500 关（段界） |
| --- | --- | --- |
| 盘面 | 8×8 | 8×8 |
| 格数 | 64 | 64 |
| 禁制数 | 10 | 10 |
| 密度 | 16% | 16% |
| 心神 | **2 盏** | **2 盏** |
| S / A / B | ≤44 秒 / ≤80 秒 / ≤133 秒 | 段内随 `lineScale` 收紧，原文未单列具体秒数 |
| `lineScale`（段内唯一旋钮） | 82% | 76% |
| 阶段新法 | 勘位：开局勘出 3 处禁位并标出 | 同左（可关：否，纯便利） |

基准 = 25 秒 × 64 ÷ 36 ≈ 44 秒，S / A / B 是它的 1 / 1.8 / 3 倍。
心神 3→2 是本段最实的变化：少一次容错，在密集盘上差别很大。依据见总览 §4。

## 2. 盘上长什么样

- 满盘 8×8 共 64 格，10 处禁制，密度仍 16%——盘变大但没变成「无处下脚」的盘。
- 盘面只有数字与 `✕` / `⚑`，不落汉字；数字按 1 / 2 / 3+ 分三段色。
- 常驻四样：`已探 X / 64`、**`阵钉 X / 10`**、**`◆◆ 心神 2 / 2`**、`S 线 44 秒`。
- 勘位开局就标出 3 处禁位——少的是需要自己推的禁位，多的是起点信息；次数与判定一个字没动。

## 3. 评级与代价

| 关 | S | A | B | 心神（容错） | 误触 | 超时 |
| --- | --- | --- | --- | --- | --- | --- |
| 201（段首） | ≤44 秒 | ≤80 秒 | ≤133 秒 | 2 盏 | 折 1 盏 + 那处显形 | 走火 F |
| 500（段界） | 段内收 6%，原文未单列秒数 | 同左 | 同左 | 2 盏 | 折 1 盏 + 那处显形 | 走火 F |

S / A / B 基准抬到 44 / 80 / 133 秒（仍给足）。代价的收紧在心神：2 盏意味着只容错两次，
第三次误触直接走火 F，没有「再来一次」的余地。

## 4. 这一段在教什么

教「容错变少时怎么稳住推理」。盘从 49 涨到 64 格，心神却从 3 盏减到 2 盏——玩家不能再靠误触试错，
得让每一步都建立在确定的约束上。勘位标出 3 处禁位正是给这个目标铺路：它把最费推的起点信息先给出来，
让玩家把注意力放在中后段的约束链上。

## 5. 会在哪掉段

- **第 201 关换段处**：没注意到心神从 3 变 2，还按旧容错习惯试错，第三次误触直接走火 F。
- **第 500 关前后**：`lineScale` 收到 76%，S 线比段首紧 6%，64 格上按旧节奏推会掉出 S。
- **勘位给的信息没用上**：开局标出 3 处禁位后仍从头盲推，时间线会被浪费在已知的格上。

## 6. 这一段的待验

- **2 盏心神是否劝退**：少一次容错，在密集盘上差别很大；本段是首次降到 2 盏的一段，
  圆满段（9×9）同为 2 盏，真机验证一并在此看。
- 若 9×9 的点击精度不够，退到 8×8（64 格）并把绝境的禁制数提到 11，密度仍在区间内——
  这条兜底以本段 8×8 盘为落点（见圆满篇 §6 的触发条件）。
- 全门性待验见总览 §7，本段不重复。
