# 小成（第三段 · 第 51–200 关）

> 花色第一次从 5 增到 6：同色候选被压少，「普通 → 困难」只动这一个数。
> 盘面 7×7 → 8×8、起手时辰 64 息、罚息仍是 −2 息，每手产出从 66 掉到 56——同样分数更难拿。

## 1. 参数与规格

`MATCH_LEVELS` 第三段那一整行——只多一色之后，盘、时辰、罚息与评级线落在哪。

| 项 | 第 51 关（段首） | 第 200 关（段界） |
| --- | --- | --- |
| 盘面 | 8×8 = 64 格，铺满 | 同左（段内不换副） |
| 花色（`kinds`） | **6** | 6 |
| 时辰 | 64 息 | 45 息 |
| 无效互换 | −2 息 | −2 息 |
| 重排 | −3 息，不限次 | 同左 |
| 照畦（提示） | −2 息，不限次 | 同左 |
| 石皮封印 | 0 格 | 0 格 |
| S / A / B | ≥2137 / ≥1454 / ≥855 | ≥1492 / ≥1015 / ≥597 |
| 阶段新法 | 无 | 无 |

**这一段 S 线掉得最多**（段首就从 2614 → 2137），原因只有一个：多了一色，
每手产出实测从 66 掉到 56（六色盘上凑三连要更多手）。时辰只从 66 收到 64，所以少掉的那截
全记在「花色」账上。口径见[总览](总览.md) §4.2。

## 2. 盘面介绍

- 8×8 满盘，6 色（`crest` 前 6 张），每格约 39px @2x；准备页写「8×8 盘 · 6 色 · 64 息 · 换不出少 2 息 · S 2137 分」。
- 同色候选比第二段少，找三连要靠扫盘与记忆，不再是一眼可见。
- 无效互换轻震、三拍演出（留空 → 落下 → 再查一轮）、`tipFor()` 现拼「换不出三连少 2 息」，均与第二段同。
- 本段盘上**仍然没有石皮**：64 格全是活的。

## 3. 评级与判定

| 关 | 时辰 | S | A | B | F |
| --- | --- | --- | --- | --- | --- |
| 51（段首） | 64 息 | ≥2137 | ≥1454 | ≥855 | 无 F |
| 125（段中） | 54 息 | ≥1814 | ≥1234 | ≥726 | 无 F |
| 200（段界） | 45 息 | ≥1492 | ≥1015 | ≥597 | 无 F |

S 线降到 2137，是因为「普通 → 困难：多一色」——花色越多，同样手数凑出的分越少（见总览 §4.2）。
这是整表管理里「每一步只动一两个数」中「多一色」那一步；罚息与重排相对第二段一字未动。

## 4. 设计意图

我这一段教的是「在更多花色里找三连」。5 → 6 色把同色候选压少，盘上不再到处是现成的三连；
玩家要建立「先扫一遍哪三株同色、再决定换哪两株」的习惯。
罚息不变（−2 息），所以这一段不靠更重的代价，而靠**候选变少后的观察成本**拉开难度。

**为什么 150 关里一直不加新机制**：这一段本身已经换了两件事（盘面 + 花色），
再加一条规则会让玩家分不清「难在哪」。规则加法统一放在下一段。

## 5. 常见失误

- **第 51 关（段首）**：花色从 5 跳到 6，前两段「一眼能看到三连」的直觉开始失灵。
- **段内后程**：段内 `duration` 继续收紧（64 → 45 息）；扫盘慢的玩家会先被时间压住。
- **硬换不成的连按**：无效互换 −2 息 + 两株抖动 + 轻震，连续误判会把息迅速磨穿。

## 6. 待验

- **每手产出 56 这个实测值准不准**：它是本段 S 线的唯一输入（见总览 §4.2），
  实测方法是「每档 40 局、假时钟推到 400 手」。真机上手速与假时钟差多少，直接决定 S 线是偏松还是偏紧。
- 8×8 盘每格约 39px，果器纹在 4.7 寸屏上还认得出 6 种花色吗（认不出就是「难度来自看不清」，不是来自候选变少）。
- 本段其余待验条目与全门重合，见总览 §7，不重复。
