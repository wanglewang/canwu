# 未入门（第一段 · 第 1–10 关）

> 6×6 盘、5 色、时辰 66 → 48 息、罚息最轻（无效互换 −1 息）、重排与照畦都不限次。
> 本段纹样「灵植」：苹果 / 茶盏 / 灵芝 / 灵梨 / 葡萄，五族分别是圆润 / 方框 / 伞锥 / 竖长 / 成簇。
> 这一段只教一件事：**换相邻两株凑三连**——先把「采收」这个动作立住。

最小的一副盘、最多的同色候选、最轻的罚息，都给第一段。我想让你把「采收」练成直觉，把「换哪两株能成线」这一件想清楚；连锁、代价、石皮、扫盘的压力，后面四段一样样加。

## 1. 参数与规格

`MATCH_LEVELS` 第一段那一整行——开局一副什么样的盘、带着什么代价、评级线落在哪。
时辰在段内逐关收紧，所以这里写两个实测点。

| 项 | 第 1 关（段首） | 第 10 关（段界） |
| --- | --- | --- |
| 盘面 | 6×6 = 36 格，铺满 | 同左（段内不换副，换段才换） |
| 花色（`kinds`） | 5 | 5 |
| 时辰 | 66 息 | 48 息 |
| 无效互换 | −1 息 | −1 息 |
| 重排 | −2 息，不限次 | 同左 |
| 照畦（提示） | −1 息，不限次 | 同左 |
| 石皮封印 | 0 格 | 0 格 |
| 本局目标 | 收灵草 100 株 | 同左 |
| 评级线 | 四成时辰内做成 → S；六成半 → A；九成 → B | 同左（比例不变，时辰收紧） |
| 阶段新法 | 无 | 无 |

三条评级线由本关时辰与每手产出现算（`gradeLinesOf`）：S 对应「用掉四成时辰就做成目标」，
A 六成半、B 九成（口径见[总览](总览.md) §4.2）。段内时辰从 66 收到 48 息，同样的比例要求的是更短的实际用时，所以段末自然更难。
**玩家在页面上看到的是这个时间口径，不是分数线**——分只在局内做即时反馈。

## 2. 盘面介绍

- 6×6 满盘灵植（全门最小的一副盘），每格约 50px @2x；图案用 `crest` sprite（本段用前 5 张）。
- 点相邻两株换位，三株同色连成一线（横或竖 ≥3）即采收。收走的三株在盘上留空 170ms，再按距离落下、顶上补新苗（三拍见总览 §5.1）。
- 没有可行换位时自动重排，绝不卡死；本段重排不限次、每次 2 息。
- 本段盘上**没有石皮**：36 格全是活的，想动哪格就动哪格。
- 准备页难度栏写清「6×6 盘 · 5 色 · 66 息 · 换不出少 1 息 · 重排少 2 息 · 四成时辰内做成 S」；局内代价句「换不出三连少 1 息」由 `tipFor()` 现拼。

## 3. 评级与判定

| 关 | 时辰 | 目标 | 评级线（用掉几成时辰做成） |
| --- | --- | --- | --- |
| 1（段首） | 66 息 | 收 100 株 | S ≤ 四成 · A ≤ 六成半 · B ≤ 九成 |
| 6（段中） | 56 息 | 收 100 株 | 同上 |
| 10（段界） | 48 息 | 收 100 株 | 同上 |

三条线同源（`MATCH_GRADE_X`），各自对应一个用时比例，**不是彼此的固定倍数**：
写成「A = S×0.68」那种派生，时辰一收紧三条会一起漂，标定就对不上。
**本段不报 F**：时辰走到头还没凑够 100 株，算未走通——熟练度照给、进度不推，但不判负。
无效互换 −1 息，让「想好了再换」从第一段就成立（见总览 §4.3）。

## 4. 设计意图

我第一段教的是「采收」本身：相邻两株互换、横或竖三株同色即收、落下还能连锁。
5 色盘上同色候选多、三连容易凑，认知负担只有「哪两株换了能成线」这一件。
罚息最轻（−1 息），所以第一段允许试错，但仍不让「狂换」成为搜索工具。

**本段故意不给的两样**：石皮与重排限次。前十关是玩家唯一会「专心学一个动作」的窗口，
往里塞第二条规则，学到的会是「这游戏很麻烦」而不是「三连怎么找」。
**目标却必须有**：终点是「做成即收工」，没有目标的段就没有终点条件——
玩家会在那一段学成「等表走完」。所以第一段给了最简单的计数目标（收 100 株，不指定色），
它不需要读字、也不改最优解，只负责让玩家第一次体验到「做完了就收工」。

## 5. 常见失误

- **第 1 关**：首局有入门卡与 goal「换相邻两株凑三连」；没看词条就上手的人会把「相邻」误当「任意两株」。
- **第 10 关（段界）**：时辰已收到 48 息（起手 66），前几关靠慢慢找线打的分在这里会缩水。
- **无效互换连按**：换不出三连少 1 息，两株各抖一下（横向 ±7rpx 三次回正）；连按会把息迅速磨掉。

## 本段没有的三样

符箓、挪苗、劫变都在后四段才开：第一段只教「换相邻两株凑三连」。
提前上任何一样，玩家第一局要同时管的东西就超过一件。（目标不算——它是终点条件，不是新规则。）

## 6. 待验

- 6×6 盘 36 格在 4.7 寸屏上每格约 50px，相邻两株互换的误触率（全门性，总览 §7 已列，本段重点看小屏）。
- 48 息够不够一个从没玩过三消的人在第十关做成 100 株（约 33 次三连）。这条得让人真打一遍：
  模拟里认真打 95% 做得成，真人第一次上手会低不少，但低到八成以下就说明目标定硬了。
- 本段其余待验条目与全门重合，见总览 §7，不重复。
