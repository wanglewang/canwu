# 入门（第二段 · 第 11–50 关）

> 盘面 6×6 → 7×7、仍是 5 色，起手时辰回到 66 息（上一段末关 48 息）、罚息 −1 → −2 息。
> 这一段练的是**想好了再换**——无效互换的代价开始真正咬人。

## 1. 参数与规格

`MATCH_LEVELS` 第二段那一整行——盘、时辰、罚息怎么抬，评级线怎么落。

| 项 | 第 11 关（段首） | 第 50 关（段界） |
| --- | --- | --- |
| 盘面 | 7×7 = 49 格，铺满 | 同左（段内不换副） |
| 花色（`kinds`） | 5 | 5 |
| 时辰 | 66 息 | 46 息 |
| 无效互换 | −2 息 | −2 息 |
| 重排 | −3 息，不限次 | 同左 |
| 照畦（提示） | −2 息，不限次 | 同左 |
| 石皮封印 | 0 格 | 0 格 |
| S / A / B | ≥2614 / ≥1778 / ≥1046 | ≥1806 / ≥1229 / ≥723 |
| 阶段新法 | 无 | 无 |

本段 S 线起点（2614）与上一段完全相同——**这不是没改**：花色还是 5、每手产出还是 66 分、
起手时辰还是 66 息，所以按公式算出来就是同一个数。真正变的是盘面（6×6 → 7×7）
与罚息（−1 → −2）：同色候选一样多，但铺在 49 格上，扫一遍要更久。
口径见[总览](总览.md) §4.2。

## 2. 盘面介绍

- 7×7 满盘、5 色（`crest` 前 5 张），每格约 45px @2x；准备页写「7×7 盘 · 5 色 · 66 息 · 换不出少 2 息 · S 2614 分」。
- 无效互换两株各抖一下（横向 ±7rpx 三次回正）+ 轻震反馈，与连锁的中量震动区分。
- 局内代价句由 `tipFor()` 现拼为「换不出三连少 2 息」，不写死。
- 收走留空 170ms、再按距离落下（`cell--clear` → `cell--fall`），连锁逐层各演一遍——看不到落下，连锁就像凭空发生（见总览 §5.1）。
- 本段盘上**仍然没有石皮**：7×7 全是活格。规则加法留到大成。

## 3. 评级与判定

| 关 | 时辰 | S | A | B | F |
| --- | --- | --- | --- | --- | --- |
| 11（段首） | 66 息 | ≥2614 | ≥1778 | ≥1046 | 无 F |
| 30（段中） | 56 息 | ≥2186 | ≥1487 | ≥875 | 无 F |
| 50（段界） | 46 息 | ≥1806 | ≥1229 | ≥723 | 无 F |

本段变的是盘面 6×6 → 7×7、罚息 −1 → −2、重排 −3、照畦 −2，代价全面抬一档。
S 线按公式跟着时辰走（66 → 46 息 ⇒ 2614 → 1806），三条线同源：A = S × 0.68、B = S × 0.4。

## 4. 设计意图

我这一段教的是「代价意识」。5 色没变，所以找三连本身不难；难的是每次无效互换都少 2 息、重排少 3 息，
玩家不能靠「狂换」试出三连——换位成了搜索工具时，罚息就是让搜索变贵（见总览 §4.3）。
连锁从这里开始成为追分的主要手段：落下后再次成线，一层比一层值钱。

**本段故意只加代价、不加规则**：上一段刚学会「找线」，这一段先让它变贵；
等到第四段才动规则（石皮），玩家才分得清「我手慢了」和「这游戏换了玩法」。

## 5. 常见失误

- **第 11 关（段首）**：盘面从 6×6 换成 7×7、罚息从 −1 跳到 −2、重排从 2 息涨到 3 息，沿用第一段「随手换着试」的打法会迅速掉息。
- **段内后程**：段内 `duration` 继续收紧（66 → 46 息），没形成「先找线再换」习惯的人会追不上 S 线。
- **第 50 关（段界）**：46 息配 1806 的 S 线，错两三次就把追分空间赔光。

## 6. 待验

- **S 线在换段那一关「跳回 2614」会不会被读成 bug**：玩家刚在上一段末关看到 1901，进新段却看到 2614。
  准备页与局内都写了「按本关时辰现算」，但真机上玩家会不会先怀疑算错了——得看一局。
- 7×7 盘 49 格在 4.7 寸屏上每格约 45px，误触率比上一段高一档（全门性的一半，另一半见总览 §7）。
