# 阵法·燃灯诀 → 阵灯推演

> 点一格，它和上下左右四格一起翻转。给定一副打乱的局面和一笔步数预算，把整盘点亮。

- 功法：阵法·燃灯诀（地阶，variance +5%）｜玩法 id：`arrayEye`｜阶段新法：死门 / 双门
- 时长基准 `base = 42`

## 1. 盘面

方格盘，按档 3×3 → 4×4 → 5×5。灯只有两种状态：亮 `●` / 灭 `○`。大成之后多一格**暗红 ✕ 死门**。

- 点一格 → 自身与四邻翻转（十字，不含对角）；
- 点的时候五格同步闪一拍（一次性微光，连点同一格交替重播）；
- 盘面不写汉字，亮灭靠实心/空心 + 底色对比。

## 2. 规则

| 项 | 规则 |
| --- | --- |
| 目标 | 步数预算内把整盘点亮 |
| 破阵 | 全亮即结束，一局只推一盘 |
| 阵溃（F） | 预算走完还没全亮 |
| 步数 | HUD 显示「已走 / 最优」 |
| 死门（大成） | 点到 ✕ 格 → 整盘复位并**罚 3 步** |
| 双门（圆满） | 死门增至两格 |

**没有「时间」这个维度**：想得久不扣分。压力从「快」变成「省」。

## 3. 操作

点击（`tap`）。另有三个辅助：`hint`（阵眼感应）、`reset`（复原本局）、`undo`（不提供）。

**用一次感应或重置，本盘最高只到 A**。辅助不是扣分，是**让出最高档**——两类玩家都能通关，S 留给纯推演。

## 4. 五档参数

| 档 | 盘面 | 最优步数下限 | 步数预算 |
| --- | --- | --- | --- |
| 简单 | 3×3 | 2 步 | 9 步 |
| 普通 | 3×3 | 3 步 | 12 步 |
| 困难 | 4×4 | 4 步 | 16 步 |
| 极难 | 4×4 | 5 步 | 18 步 |
| 绝境 | 5×5 | 5 步 | 22 步 |

**规格与最优步数下限同时递增**。只放大盘面不够：4×4 上三两步就解开的盘，反而比 3×3 上四步的更轻松，档位会看起来倒挂。

预算按最优步数留三档余量——够 A，不够乱点。

## 5. 评级

按「已走步数 ÷ 本盘最优步数」：

| 评级 | 条件 |
| --- | --- |
| S | 正好最优步数 |
| A | 多 2 步以内 |
| B | 不超过最优的两倍 |
| C | 解开但走了太多步 |
| F | 预算耗尽阵溃 |

**S 只给没借外力的推演**（见第 3 节）。

## 6. 阶段新法

| 段位 | 名 | 规则 | 可关 |
| --- | --- | --- | --- |
| 大成 | 死门 | 盘上多一格暗红 ✕，点到整盘复位并罚 3 步 | 是 |
| 圆满 | 双门 | 死门增至两格 | 是 |

死门把「不能碰的格」加进了推演——它不只是障碍，还会**打乱你刚推好的局**（整盘复位）。所以「罚 3 步」其实是次要的，主要代价是重来。

## 7. 首局手把手

第一次进入这一门（`onboarded === false`）会先进一盘「两步解的小阵」：

1. 第一手：看「点一格翻五格」；
2. 第二手：看「四邻一起回来」；
3. 走完全亮后停一拍，再进正式局。

教学盘**不计步、不结算、不进统计**；随时可跳过；跳过或走完都记「看过」，之后不再出现。教学盘与真局同构，手感能直接迁移。

## 8. 设计依据

### 为什么从「限时连解」改成「一盘推演」

早期是「36 秒内解尽量多盘」，按解开盘数评级。两个问题：

1. **逻辑推演最怕倒计时**：想得越久解得越少，玩家被推着乱点而不是推演；
2. **与静心诀、三秀诀品类同构**：都是「限时内做尽量多」，删掉文案后分不出。

改成步数预算后，压力从「快」变成「省」，这一门才真正变成「推演」。

### 为什么求解用 GF(2) 而不是穷举

4×4 有 16 个变量、5×5 有 25 个。穷举分别要 6.5 万与 3355 万次，生成一盘就卡死。GF(2) 高斯消元 + 零空间枚举是 25³ 量级，基本瞬时（5×5 生成 40 局约 3ms）。

顺带解决了「生成时保证最优步数」：解出来多长就是多长，不靠随机点几下碰运气。

### 为什么辅助封顶 A 而不是扣分

扣分可以让玩家「用辅助也拿 S，只是分低一点」——但这一门的评级**就是**「省步数」，用了感应等于直接被告知下一步，那就不再是省。

让它让出最高档，比扣一个抽象的分更诚实。

### 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 限时连解（旧版） | 见上 |
| 穷举求解 | 卡死 |
| 辅助扣分但可拿 S | 见上 |
| 死门罚时间 | 这一门没有时间，罚时间无意义；罚步数才落在同一把尺子上 |
| 盘面写「亮 / 灭」汉字 | 盘面不写汉字 |
| 一局多盘 | 多盘会让「最优步数」失去焦点，且与「省」的主题冲突 |

## 10. 待验（必须真机）

- 4×4 / 5×5 的格子尺寸在 4.7 寸屏的误触率，以及「点一格翻五格」在 5×5 上还看不看得清。
- 「余 N 步」在推演中够不够用；S 档（一步不浪费）对刚上手的人是否过于苛刻。
- 重置与感应两个按钮并排是否挤；按下后「本盘最高 A」有没有被看见。
- 阵溃（走火 F）会不会让人以为完全白玩一场。
- 纸色底上 `●` / `○` 与暗红 `✕` 的辨识度（含色弱视角）。
- 破阵整盘泛金在纸色底上够不够亮又不刺眼。
- 死门从「罚 3 秒」改成「罚 3 步」之后的手感差异。
