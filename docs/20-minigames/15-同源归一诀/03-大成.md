# 大成（第四段 · 第 201–500 关）

> 目标抬到 512，起手仍是 3 块，fourRate 从 0.300 收到 0.250。
> 两个旋钮同时往前推：更长的路 + 更少的白送 4。

## 1. 参数与规格

| 项 | 第 201 关（段首） | 第 500 关（段界） |
| --- | --- | --- |
| 盘面 | 4×4 | 4×4（整段不变） |
| 目标块 | 512 | 512（整段不变） |
| 起手块 | 3 | 3（整段不变） |
| fourRate（起手给 4 的概率） | 0.300 | 0.250 |
| S | 合出 512 | 合出 512 |
| A | 256 | 256 |
| B | 128 | 128 |
| C | 没到 128 | 没到 128 |

这是「五段参数」第四行的展开：目标 512、起手 3。盘面仍是 4×4，
变的是目标块与 fourRate——目标越高需要的步数越多，白送的 4 越少越要自己凑。

## 2. 盘面介绍

- 开局 3 块，HUD 分母换成 512；一路合到 512 才结束，中途的 256 只是 A 线。
- 最大块的金边从开局就挂在最大的那块上，随着合成往上翻（128 → 256 → 512）。
- 牌面底色编码在这里真正有用：三位数（128 / 256）与四位数（512）自动小一号，
  扫一眼就能看出大块在哪个角，不至于把 512 挤成一片糊。

## 3. 评级与判定

| 关 | S | A | B | C | F |
| --- | --- | --- | --- | --- | --- |
| 201 | 合出 512 | 256 | 128 | 没到 128 | 盘满且相邻无同数 |
| 500 | 合出 512 | 256 | 128 | 没到 128 | 同上 |

S / A / B / C 四线按目标 512 / 256 / 128 走。
本段 fourRate 0.300 → 0.250，盘满推不动判 F。A 线（256）正好是上一段的目标，
意味着这一段「差一点」的局在上一段已经是「完成」——达成线在整体上移。

## 4. 设计意图

我这一段教的是「两件事一起变紧」：目标从 256 翻到 512，白送的 4 又从 0.300 收到 0.250。
玩家不能只靠把上一段的操作重复得更久，必须把「留大块在一角、留出推盘通道」变成习惯，
否则目标越高，盘满死局来得越早。

## 5. 常见失误

- **第 201 关**：目标从 256 跳到 512，A 线变成 256；玩家容易把合出 256 当成「差不多了」而松劲。
- **第 350 关前后**：fourRate 约 0.275（据 `tweakParams` 折算），起手越来越少给 4，
  凑同要多推几步，盘面也更早被填慢。
- **第 500 关（段界）**：fourRate 落到 0.250，目标 512 需要一路合到底，容错空间明显收窄。
