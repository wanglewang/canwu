# 术数·九宫排数诀 → 九宫填数

> 九宫盘上留着空格，每行、每列、每宫都要把 1 到 N 各填一遍。填错一格记十秒，时辰到还没填完即收功。

- 功法：术数·九宫排数诀（黄阶，qiSave −9%）｜玩法 id：`shudu`｜无阶段新法
- 时长基准 `base = 38`

## 1. 盘面

方格盘，规格按档：4×4 → 6×6 → 9×9。

- 4×4 是 2×2 宫，6×6 是 2×3 宫，9×9 是 3×3 宫；
- 挖掉的格子数按档递增（8 → 46）；
- 数字直接显示（这一门不换图案，数字本身就是内容）。

## 2. 规则

| 项 | 规则 |
| --- | --- |
| 目标 | 每行、每列、每宫各填一遍 1…N |
| 完成 | 填满且全对 |
| 填错 | 罚 **10 秒**（数落错了地方，得回头改） |
| 未完成 | 时辰到还没填完 → **走火 F** |
| 挖洞 | 生成时逐格验证「解仍唯一」，否则重挖 |

**「解唯一」是硬要求**：如果有多个解，玩家填出一个合法解却被告知错，那是设计缺陷而不是难度。

## 3. 操作

- 点格子 → 选中
- 点数字键 → 落子
- 点 `✕` → 清空该格

三段式操作，与落石 / 滑格的「方向键」区分开。

## 4. 五档参数

| 档 | 盘面 | 挖洞 | 时限 | S | A | B |
| --- | --- | --- | --- | --- | --- | --- |
| 简单 | 4×4 | 8 | 150 秒 | ≤45 秒 | ≤70 秒 | ≤100 秒 |
| 普通 | 6×6 | 14 | 240 秒 | ≤80 秒 | ≤120 秒 | ≤170 秒 |
| 困难 | 9×9 | 32 | 420 秒 | ≤170 秒 | ≤240 秒 | ≤330 秒 |
| 极难 | 9×9 | 40 | 420 秒 | ≤190 秒 | ≤270 秒 | ≤370 秒 |
| 绝境 | 9×9 | 46 | 420 秒 | ≤210 秒 | ≤300 秒 | ≤410 秒 |

**时限给得比 B 线宽一截**（420 vs 330–410），是为了让「填完但慢」还有个 C，而不是一超线就直接判负——**没填完（F）和填得慢（C）是两件事**。

## 5. 设计依据

### 为什么是规格递进而不是收紧时间

4×4 先把「行、列、宫各一遍」这个规则看懂；6×6 换宫格形状（2×3）；9×9 才是正经数独。

如果只在 4×4 上收紧时间，玩家永远学不会 9×9 的宫格约束——**规则理解需要盘面来教**。

### 与阵灯推演的分工

| | 阵灯推演 | 九宫填数 |
| --- | --- | --- |
| 改状态 | 点一格改一片（联动） | 填一格只改一格（无联动） |
| 比什么 | 省步数（想得久不扣） | 快（含罚时） |
| 失败 | 阵溃（预算耗尽） | 时辰到没填完 |

一个是「联动推演」，一个是「静态约束求解」。

### 填错罚 10 秒而不是判负

数独的错通常是「这一格填 5 但接下来推不下去」。如果直接判负，玩家会极度谨慎，一局打得极慢。

罚 10 秒的语义是「回头改」，允许试错，但试错要付时间。10 秒约等于「两三次犹豫」。

### 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 允许非唯一解 | 玩家填对却说错，是设计缺陷 |
| 填错即判负 | 见上 |
| 只有 9×9 | 4×4 / 6×6 是教规则的台阶 |
| 用图案代替数字 | 数独的内容就是数字，换图案等于换玩法 |
| 时限只给到 B 线 | 「填完但慢」会无处落脚，只能判 F |

## 7. 待验

- 9×9 在 4.7 寸屏上每格约 36px，点格 + 数字键两段操作是否够快（填一格要两次点击）。
- 数字键区占用的纵向空间是否挤压盘面（9×9 + 10 个数字键同屏）。
- 420 秒（7 分钟）一局是否超出「碎片时间」的定位——这是全站最长的一局，与「30–90 秒」的主力区间差距很大。
- 挖洞 46 格的 9×9 是否真的「纯推理可解」，还是会出现需要猜测的局面。
