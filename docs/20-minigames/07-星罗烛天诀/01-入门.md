# 入门（第2段 · 第 11–50 关）

> 盘面仍是 3×3，但最优步数升到 4–5 步——同尺寸的两段靠「最优区间不重叠」分开，推演要更绕。
>
> 这一段我想让玩家把刚学会的手法用得更深：盘面没变，解法却长了。难度不是换一张新盘吓你，
> 是同一张盘上要你多推两步——这是「同一件事本身变了」的第一级台阶。

## 1. 这一段（40 关）的盘与参数

这张表先把本段的盘与步数摆出来——段首段界各是什么，一眼可查：

| 项 | 第 11 关（段首） | 第 50 关（段界） |
| --- | --- | --- |
| 盘面 | 3×3（9 格） | 3×3（9 格） |
| 最优步数 | 4–5 步 | 4–5 步（段内不动，`sanity` 守着） |
| 步数余量 | +7 步 | +5 步（段内从 7 收到 5，段内跨度） |

原文这一段给余量 +7；另明确「余量在段内从 7 收到 5」，故段首 +7 / 段界 +5，为段内跨度。盘面与最优步数段内不变。

## 2. 盘上长什么样

- 3×3 方格盘，亮 `●` / 灭 `○`，点一格翻自身与四邻（十字）；五格同步闪一拍。
- 本段最优 4–5 步，与上段 2–3 步的区间不重叠——这是原文「相邻两段至少一条轴真的动了」在同尺寸下的落点。
- HUD 只报最优 / 已走 / 多走三步数与「余 R 步」；不显示「已亮 N / M」，不放进度条。

## 4. 这一段在教什么

盘面不变、最优解变长：玩家要在同样 3×3 上定出 4–5 步的点法。难度靠「解更长、更容易多走冗余手」推进，
而不是换盘面——盘面要到下一段才升 4×4（依据见总览 §3）。

## 5. 会在哪掉段

原文没有逐关记失误点，我按这一段的机制把真正会让你掉段的情况列出来：

- 第 11 关起：4–5 步解比上段绕，多走几手就出 B 带（冗余 >5）甚至阵溃（满余量）。
- 整盘点亮但冗余超 B 线 → 落到 C。
- 用感应看整条解（每眼 2 步）→ 余量被吃掉；旧版「感应免费 + 封顶 A」的反向激励已修掉（依据见总览 §2）。
