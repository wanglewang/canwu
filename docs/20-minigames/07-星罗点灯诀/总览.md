## 1. 盘面骨架（五段共用）

方格盘，按段 3×3 → 4×4 → 5×5。灯只有两种状态：亮 `●` / 灭 `○`。大成之后多一格**暗红 ✕ 死门**。

- 点一格 → 自身与四邻翻转（十字，不含对角）；
- 点的时候五格同步闪一拍（一次性微光，连点同一格交替重播）；
- 盘面不写汉字，亮灭靠实心/空心 + 底色对比。

**盘上不显示「已亮 N / M」，也不放进度条。** 亮着的盏数与「离解开还有多远」没有关系：
实测 5×5 上 **37.6% 的正确一手会让已亮数变少**。一个会倒退的进度条不是反馈，是一句反话。
局内只留三个真数字——最优几步、已走几步、余几步（见 §2）。**首局教学盘同样不报这个数**：正式局没有它，
教学里先教会玩家看它，等于先教一个下一局就消失的判据；教学要看的是哪几格一起翻转，不是计数。

### 1.1 首局手把手（原文 §7）

第一次进入这一门（`onboarded === false`）会先进一盘「两步解的小阵」：

1. 第一手：看「点一格翻五格」；
2. 第二手：看「四邻一起回来」；
3. 走完全亮后停一拍，再进正式局。

教学盘**不计步、不结算、不进统计**；随时可跳过；跳过或走完都记「看过」，之后不再出现。教学盘与真局同构，手感能直接迁移。

## 2. 规则骨架（五段共用）

| 项 | 规则 |
| --- | --- |
| 目标 | 余量内把整盘点亮 |
| 破阵 | 全亮即结束，一局只推一盘 |
| 阵溃（F） | 比最优多走满「余量」还没全亮 |
| 步数 | HUD 写「最优 N 步 · 已走 M 步 · 多走 K 步」与左上「余 R 步」 |
| 死门（大成） | 这一格点不动；误触**罚 2 步**，盘面不动 |
| 双门（圆满） | 死门增至两格 |
| 阵眼感应 | 每看一眼**算 2 步**（花的是同一份余量） |
| 复原本局 | 每局**只许一次**；步数清零、盘面回开局，本盘最高只到 A |

**没有「时间」这个维度**：想得久不扣分。压力从「快」变成「省」。

「余 R 步」= 本盘最优 + 余量 − 已走。它不是一个写死的常数：**余量固定，预算跟着本盘最优走**。
旧版把预算写成绝对数（9 / 12 / 16 / 18 / 22），而最优是随机生成的，于是预算成了最优的 3–4.5 倍——
玩家要白白浪费到四倍才阵溃，压力等于没有，文档里那句「够 A、不够乱点」也从来没对过。

**操作**：点击（`tap`）。另有三个辅助：`hint`（阵眼感应）、`reset`（复原本局）、`undo`（不提供）。
辅助不是抽象扣分，也不是「只封顶不折步」：**它花的是同一份余量**。

- 感应看一眼 = 2 步，看几眼评级就往下掉，看满一手直接阵溃（5×5 绝境是 8–9 步解，最多看 7 眼就已经没钱走完了）；
- 复原本局 = 每局一次，换来一次干净的盘面，代价是本盘最高只到 A；
- 没有撤销：这一门的评价单位是「冗余手数」，撤销等于免费抹掉冗余，那五段就只剩 S 一段。

**为什么不沿用「感应免费、封顶 A」**：它制造了一个反向激励。诚实推演但多走 3 步只能拿 B（倍率 ×1.0），
而用感应抄完整条最优解反而保底 A（×1.2）——辅助不是「让出最后段」，而是**比诚实犯错更划算**。
旧版还有第二层：感应不限次，等于「看答案」按钮；玩家一旦确认 S 已死（HUD 写着最优几步，一眼就能看出），
理性选择就是立刻转去刷感应。五段因此塌成「S 或 A」两段，B/C/F 只落在不懂规则的人头上。

### 2.1 评级（按冗余手数，非分数）

按「比本盘最优多走了几步」（冗余手数 = 已走 − 最优）：

| 评级 | 条件（余量 7 的段） |
| --- | --- |
| S | 冗余 0 手 |
| A | 冗余 2 手以内 |
| B | 冗余 5 手以内 |
| C | 解开，但冗余超过 B 线 |
| F | 冗余满 7 手还没全亮（阵溃） |

五段的宽窄是 0 / 2 / 3 / 2，**每一段、每一盘都一样**。余量在段内收到 5 时，A 线恒为多 2 步、B 线 = 余量 − 2、F 线 = 满余量；
段界关（余量 5）的评级线按此在段篇 §3 展开，原文未为余量 5 单列评级表。

旧版按「已走 ÷ 最优」评：S 正好最优、A 多 2 步内、B 两倍最优以内。这套倍数在两种盘上都是坏的：

- **未入门段 B 带不存在**：最优 2 步时，A 线（2+2=4）与 B 线（2×2=4）是同一条线，而 A 先判，B 永远不会出现；
- **C 带宽度随盘浮动**：最优 5 步的盘，B 线宽到 10 步、C 只剩十一二步那两格；最优 2 步的盘，C 有 5 格宽。
  同样是「多浪费 4 手」，抽到 5 步解的盘是 B，抽到 3 步解的盘就是 C——**B 与 C 的分界不取决于你怎么走，取决于抽到哪盘**。

换成绝对冗余手数之后，这两条一起消失。

### 2.2 阶段新法（两条都是「改规则」）

| 段位 | 名 | 规则 | 可关 |
| --- | --- | --- | --- |
| 大成 | 死门 | 盘上多一格暗红 ✕，这一格点不动；误触罚 2 步 | 是 |
| 圆满 | 双门 | 死门增至两格 | 是 |

死门的代价从「整盘复位 + 罚 3 步」改成「这一格点不动 + 罚 2 步」，理由不是手软：

- **复位整盘等于用一根手指的精度否掉一整盘已经推好的局**。这一门说好了「想得久不扣分」，那就不该让手抖决定成败——
  5×5 上推了二十手，误触一格全部推倒，玩家学到的不是「别碰死门」，是「这一门不值得认真推」。
- **复位与「复原本局」按钮撞成了两种价**：同一件事（盘面回开局），按钮做要封顶 A，误触做只罚 3 步，还更便宜。
  同一件事两条价格，规则就不可解释了。
- **开局第一手误触死门时盘面一格没变**，只少了 3 步：玩家看不见任何变化，只觉得「点了没反应还扣了步数」。

现在的死门是纯粹的「这一格不能用」：它把可点集缩小、把最优解逼长，是加规则，不是加手速。

## 3. 五段怎么变

每一段至少有一条轴真的动了（下表按原文五段参数、盘面说明与阶段新法归纳；原文没有单列「新学一件事」表）：

| 段 | 这一段新学的一件事 | 轴 |
| --- | --- | --- |
| 一 · 未入门 | 3×3、2–3 步解：点一格翻五格 | 盘面 + 步数 |
| 二 · 入门 | 同尺寸但最优步数升到 4–5（区间不与上段重叠） | 步数 |
| 三 · 小成 | 升到 4×4——「行追法必成」的一段，学一套机械手法 | 盘面 |
| 四 · 大成 | 升到 5×5、6–7 步 + 死门（这一格点不动） | 盘面 + 步数 + 规则 |
| 五 · 圆满 | 同尺寸但最优升到 8–9 + 双门（死门增至两格） | 步数 + 规则 |

**相邻两段至少有一条轴真的动了**：同尺寸的两段，最优步数区间不重叠（2–3 ｜ 4–5，6–7 ｜ 8–9）；
不同尺寸的两段靠盘面分（3×3 → 4×4 → 5×5）。

旧表是「盘面 3/3/4/4/5 + 最优 2–4 / 3–5 / 4–6 / 5–7 / 5–7」，简单与普通有三分之二的盘重合，
极难与绝境的最优区间**完全一样**——五段实际只有三段，另外两段只是标题换了。
现在同尺寸靠最优区间不重叠、不同尺寸靠盘面分，五段才真的是五段。

## 4. 设计依据

### 4.1 为什么从「限时连解」改成「一盘推演」

早期是「36 秒内解尽量多盘」，按解开盘数评级。两个问题：

1. **逻辑推演最怕倒计时**：想得越久解得越少，玩家被推着乱点而不是推演；
2. **与澄心默诵诀、三秀连收诀品类同构**：都是「限时内做尽量多」，删掉文案后分不出。

改成步数余量后，压力从「快」变成「省」——但「省」要真的咬人，得同时满足三件事：预算跟着最优走（§2）、
辅助花同一份余量（§2）、反悔限次（§2）。只做第一件（旧版）等于没做。

### 4.2 为什么求解用 GF(2) 而不是穷举

4×4 有 16 个变量、5×5 有 25 个。穷举分别要 6.5 万与 3355 万次，生成一盘就卡死。
GF(2) 高斯消元 + 零空间枚举是 25³ 量级，基本瞬时（5×5 生成 40 局约 3ms）。

顺带解决了「生成时保证最优步数」：解出来多长就是多长，不靠随机点几下碰运气。生成器现在只接受落在本段 `[minSteps, hiSteps]` 里的盘——
这是段位表写下的唯一难度承诺，宽一格就名不副实。实测命中率：3×3 任意段 100%、4×4 [4,5] 约 92%、
5×5 [6,7] 与 [8,9] 约 95%，60 次重试足够。

### 4.3 为什么难度只看「冗余手数」，不看「解得多长」

这一门真正难的是「定出该点哪几格」，而解的长度几乎不影响定解——实测同一尺寸下，5 步解与 12 步解的盘**暗格数几乎一样**
（3×3 约 4.5、4×4 约 8.2、5×5 约 12.5），玩家肉眼分不出。所以最优步数只当**段位规格**用（决定这一段的盘长什么样），
不当评价用；评价只看玩家自己浪费了几手——那是他唯一能控制、也能在结算里看懂的变量。

### 4.4 为什么段内只收余量，不收最优步数

`buildParamsAt` 的收紧表原来同时乘 `minSteps` 与 `capSteps`。`minSteps` 乘 0.7 是「段末要求更短的解」，
方向是往**简单**走的——台阶数好看，难度反而倒退。现在这两个键已从收紧表里摘掉：段内只收 `budgetSlack`（7 → 5），
`sanity` 由 `tests/rank.test.js` 守着（段内最优步数区间一个字都不许动）。

### 4.5 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 限时连解（旧版） | 见 §4.1 |
| 穷举求解 | 卡死 |
| 评级按「已走 ÷ 最优」的倍数（旧版） | 未入门段 B 带不存在，C 带宽度随盘浮动，B/C 的分界变成抽签 |
| 感应免费 + 封顶 A（旧版） | 辅助比诚实犯错更划算（A ×1.2 > B ×1.0），且不限次等于「看答案」 |
| 复原本局不限次（旧版） | 预算永不咬人：任何时候按一下就把步数清零，阵溃只剩「第一次不知道有这个按钮」 |
| 死门整盘复位 + 罚 3 步（旧版） | 用手指精度否掉整盘推演；与「复原本局」撞成两种价 |
| 死门罚时间 | 这一门没有时间，罚时间无意义 |
| 盘面写「亮 / 灭」汉字 | 盘面不写汉字 |
| 一局多盘 | 多盘会让「最优步数」失去焦点，且与「省」的主题冲突 |
| HUD 显示「已亮 N / M」 | 亮盏数与解题进度无关，正确的一手也可能让它倒退 |

## 5. 界面与反馈（五项逐门过）

1. **判据**：点一格 → 自身与四邻翻转、五格同步闪一拍；全亮即破阵；亮灭靠 `●`/`○` 实心空心 + 底色对比，不写汉字。
2. **代价**：比最优多走满余量还没全亮 → 阵溃 F；死门误触罚 2 步且盘面不动；感应看一眼 2 步；复原本局每局一次、封顶 A；不提供撤销。
3. **操作**：`tap`；辅助 `hint`（阵眼感应）、`reset`（复原本局）花同一份余量；`undo` 不提供。
4. **进度**：HUD「最优 N 步 · 已走 M 步 · 多走 K 步」+ 左上「余 R 步」；**不显示「已亮 N / M」、不放进度条**，首局教学盘同样不报。
5. **收束**：全亮即结束，一局只推一盘；失败态只有阵溃 F（多走满余量还没全亮）。

## 7. 全门待验

原文 §10 待验共十条，按规范分流：两条下到段篇——「4×4 小成段行追法必成」下到 [小成篇](02-小成.md) §6、
「余量 7 够不够（绝境 8–9 步解）」下到 [圆满篇](04-圆满.md) §6；其余八条是全门性的，留这里：

- 4×4 / 5×5 的格子尺寸在 4.7 寸屏的误触率，以及「点一格翻五格」在 5×5 上还看不看得清。
- S 带（一步不浪费）对刚上手的人是否过于苛刻：现在 S 是「完全最优」，而最优解需要真的把每一格推对。
- 「感应算 2 步」有没有被看见：它写在按钮旁的代价句与局内 status 里，但玩家很可能只看到余步数字跳了一下。
- **撤掉「已亮 N / M」之后的方向感**：那个数是反向的（正确一手也可能让它变少），但撤掉之后可能有人一时找不到「我还差多少」的抓手。
  要盯的是玩家会不会改用「最优 8 / 已走 5」自己算，还是干脆乱点到阵溃。教学盘也一起撤了，第一局那两步还能不能靠「五格同时变」看懂翻转。
- 复原按钮「每局只许一次」的发现时机：提示只写在布局第一句与按钮反馈里，玩家往往在中途想复原时才知道用完了。
  要不要在余下 0 次时把按钮压暗（压暗只是先说一句，不禁用）。
- 阵溃（走火 F）会不会让人以为完全白玩一场；现在阵溃只发生在「多走满 7 步」，比旧版更容易撞上。
- 纸色底上 `●` / `○` 与暗红 `✕` 的辨识度（含色弱视角）。
- 破阵整盘泛金在纸色底上够不够亮又不刺眼。
