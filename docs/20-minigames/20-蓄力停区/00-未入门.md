# 未入门（冲击筑基 · 突破档位）

> 本门不进参悟序列，五篇按突破档位分，不是关号段。
>
> 第一次面对「手要稳」：蓄力条往复不停，松手停在红线之间就算筑基成。

## 1. 这一档的盘与代价

| 项 | 取值 | 来源 |
| --- | --- | --- |
| 突破档位 | 冲击筑基（炼气 → 筑基） | `data/world.js` 四境界 |
| 区间宽 | 16 | `zoneWidth = 16 + (perks.easy ? 6 : 0)`，筑基档 `perks.easy` 未起 |
| 区间位置 | 起点 42–71，终点 `min(96, 起点 + 16)` → 58–87 | `42 + randInt(30)` |
| 布阵灵石 | 60 | `BREAKTHROUGH_STONE[筑基]` |
| 失败退回 | 50%：退 30 枚、散 30 枚 | `BREAKTHROUGH_REFUND = 0.5` |
| 落点 | 26 个（4 的倍数），区间内约 5 个 | 蓄力值 0 ↔ 100，每跳 +4 |
| S 窗 | 55–110ms（正中 ±1 格，1–2 个落点） | `gradeAt()`，`dist <= 3` |

区间宽 16 这一支是常局宽度；`hard ? 11 : 16` 的 11 支在当前接线取不到，详见 04-圆满.md §6 与总览 §4.2。

## 2. 盘上长什么样

- 没有格子，只有一条蓄力条：蓄力值 **0 → 100 → 0** 往复，每次 tick **+4**，**55ms 一跳**。
  满程 25 跳 ≈ 1.375 秒，一次完整往返 ≈ 2.75 秒；蓄力值是 4 的倍数，共 26 个落点。
- 条上「红线之间」每局随机：起点 `42 + randInt(30)`（42%–71%），宽 16，终点 `min(96, 起点 + 16)`。
- HUD 实时报「距正中 N% · X 评」；蓄力中状态栏写「气机正盛…松手定生死」，banner「一线之间」。
- 盘上没有段位标记、没有死位、没有提示轨——这一套只在突破时出现（总览 §1）。

## 3. 评级与代价

判定见总览 §2 的 `gradeAt()` 全文：区间外 F，正中 dist ≤3/≤7/≤12 依次 S/A/B，其余 C。本档 S 窗落在 55–110ms。

| 评 | 这一档的结果 |
| --- | --- |
| S | 突破成功，结算卡标「破关」 |
| A / B / C | 突破成功（C 起步全算过） |
| F | **失败**：退 30 枚灵石（散 30 枚），境界不变 |

**只有 F 是失败**：`applyBreakthrough()` 里 `if (grade === 'F')` 走失败分支，C/B/A/S 走同一条成功分支。
评级不换收益，只换结算卡的一个字母与 banner（S 才有「破关」）——破境是成 / 不成的二元事件。

## 4. 这一档在教什么

**把手感立起来**。突破是全流程唯一的不可逆节点，最后一步若只是点「确定」，破境就变成勾清单；
加一个要求精度的手部动作，是把「临门一脚」立起来（依据见总览 §4.1）。
筑基档宽度 16、S 窗 1–2 个落点，第一次就要学会「看着 HUD 瞄、靠手眼协同停在正中」，而不是读数字。

## 5. 会在哪失手

- **松手落在区间外**（如区间 42–58 时 ≤38 或 ≥62）：F「气机偏离」，散 30 枚灵石。
- **只差正中 ±4 / ±8**：仍能成功，但只拿 A / B；S 窗只有正中 ±1 格（55–110ms），看得到却不容易停准。
- **中途结束**：也是 F，同样算失败——玩家若以为「点了取消就不算数」会吃亏（待验见 04-圆满.md §6）。
- **手抖一次**：散一半灵石（30 枚）；代价是「能感觉到疼、但不至于不敢再来」（总览 §4.5）。
