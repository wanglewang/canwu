# 入门（冲击金丹 · 突破档位）

> 本门不进参悟序列，五篇按突破档位分，不是关号段。
>
> 红线之间从 16 宽抬到 22（金丹起 +6），但不是难度奖励——是降低后期重复操作的心理成本。

金丹档我把红线从 16 放宽到 22，但要说清楚这不是「送你过关」。一个已经练到筑基的玩家，不该在冲关上因为一次手滑反复失手——宽 6 个点降的是重复操作的心理成本。可 S 窗没放宽：进区间更容易了，拿那个「破关」字母还是一样难。同时失手代价从散 30 抬到散 60，手感的门槛不变，疼感变大。

## 1. 蓄力条与参数

冲击金丹这一档，红线为什么变宽、灵石代价怎么抬。

| 项 | 取值 | 来源 |
| --- | --- | --- |
| 突破档位 | 冲击金丹（筑基 → 金丹） | `data/world.js` 四境界 |
| 区间宽 | 22（金丹起 +6） | `zoneWidth = 16 + (perks.easy ? 6 : 0)` |
| 区间位置 | 起点 42–71，终点 `min(96, 起点 + 22)` → 64–93 | `42 + randInt(30)` |
| 布阵灵石 | 120 | `BREAKTHROUGH_STONE[金丹]` |
| 失败退回 | 50%：退 60 枚、散 60 枚 | `BREAKTHROUGH_REFUND = 0.5` |
| 落点 | 26 个，22 宽里约 5–6 个落在区间内 | 蓄力值 0 ↔ 100，每跳 +4 |
| S 窗 | 仍是 1–2 个落点（55–110ms） | `gradeAt()` 的 `dist <= 3` 没变 |

`perks.easy` 的语义是「境界越高，红线之间越宽」——不是难度奖励，是**降低后期重复操作的心理成本**：
一个已经练到元婴的玩家不该在冲关上反复失手（原文 §4）。宽了 6 个点，但 S 窗没放宽。

## 2. 指针的来回

- 同一条蓄力条：0 → 100 → 0 往复，tick +4、55ms 一跳，25 跳单程 ≈ 1.375 秒，往返 ≈ 2.75 秒，26 个落点。
- 红线区间宽 22，起点 42%–71% 随机，终点 `min(96, 起点 + 22)`。
- HUD 实时报「距正中 N% · X 评」；状态栏「气机正盛…松手定生死」，banner「一线之间」。
- 没有格子、没有段位标记——规则与盘面全套沿用（总览 §1、§2）。

## 3. 停准与评级线

判定沿用总览 §2 的 `gradeAt()`，本档阈值不变。

| 评 | 这一档的结果 |
| --- | --- |
| S | 突破成功，结算卡标「破关」 |
| A / B / C | 突破成功 |
| F | **失败**：退 60 枚灵石（散 60 枚），境界不变 |

**只有 F 是失败**；评级不换收益，只换结算卡字母与 banner（总览 §2）。
宽 22 让停在区间内更容易，但 S 窗仍是 1–2 个落点——成功变容易，S 没变容易。

## 4. 这一档的稳

我这一档教的是**同一套手感，成本变了**。区间宽 +6 不是给玩家送分，而是承认「冲关是花费而非产出」：
越到后面，重复操作越不该因为一次手滑就把玩家挡在境界外（依据见总览 §4.1、§4.5）。
这一档同时把失败代价从散 30 枚抬到散 60 枚——手感的门槛不变，失手的疼感变大。

## 5. 停歪的地方

- **松手落在区间外**：F「气机偏离」，散 60 枚灵石。
- **停在区间内但离正中 ±4 / ±8**：成功但只拿 A / B；22 宽只让「进区间」变容易，S 仍是 1–2 个落点。
- **等两个来回后长按**：按住时长到 4–5 秒，持续触控可能被系统手势打断（待验见 04-圆满.md §6）。
- **中途结束**：也是 F、也退一半——玩家可能以为「点了取消就不算数」。
