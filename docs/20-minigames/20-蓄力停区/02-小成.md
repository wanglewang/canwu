# 小成（冲击元婴 · 突破档位）

> 本门不进参悟序列，五篇按突破档位分，不是关号段。
>
> 同一套停区动作，布阵抬到 240 枚灵石——失手一次散 120 枚，这是冲关代价最重的一档。

## 1. 这一档的盘与代价

| 项 | 取值 | 来源 |
| --- | --- | --- |
| 突破档位 | 冲击元婴（金丹 → 元婴，四境界最高一境） | `data/world.js` 四境界 |
| 区间宽 | 22（金丹起 +6） | `zoneWidth = 16 + (perks.easy ? 6 : 0)` |
| 区间位置 | 起点 42–71，终点 `min(96, 起点 + 22)` → 64–93 | `42 + randInt(30)` |
| 布阵灵石 | 240 | `BREAKTHROUGH_STONE[元婴]` |
| 失败退回 | 50%：退 120 枚、散 120 枚 | `BREAKTHROUGH_REFUND = 0.5` |
| 落点 | 26 个，22 宽里约 5–6 个落在区间内 | 蓄力值 0 ↔ 100，每跳 +4 |
| S 窗 | 仍是 1–2 个落点（55–110ms） | `gradeAt()` 的 `dist <= 3` 没变 |

`perks.easy` 的语义是「境界越高，红线之间越宽」——降低后期重复操作的心理成本：
一个已经练到元婴的玩家不该在冲关上反复失手（原文 §4）。这里宽 22、S 仍 1–2 个落点。

## 2. 盘上长什么样

- 蓄力条 0 → 100 → 0 往复，tick +4、55ms 一跳；单程 25 跳 ≈ 1.375 秒，往返 ≈ 2.75 秒，26 个落点。
- 红线区间宽 22，起点 42%–71% 随机，终点 `min(96, 起点 + 22)`（最大 93）。
- HUD 实时报「距正中 N% · X 评」；状态栏「气机正盛…松手定生死」，banner「一线之间」。
- 规则、盘面、判定全套沿用（总览 §1、§2），没有元婴专属的新操作。

## 3. 评级与代价

判定沿用总览 §2 的 `gradeAt()`，本档阈值不变。

| 评 | 这一档的结果 |
| --- | --- |
| S | 突破成功，结算卡标「破关」 |
| A / B / C | 突破成功 |
| F | **失败**：退 120 枚灵石（散 120 枚），境界不变 |

**只有 F 是失败**；C 起步全算过；评级不换收益，只换结算卡字母与 banner。
散 120 枚是三次冲关里最疼的一次——但仍只是「一半」，不退完也不全扣（总览 §4.5）。

## 4. 这一档在教什么

**代价的顶点，手感的延续**。冲到元婴是四境界的最后一步：盘面没变、判定没变、S 窗没变，
变的是布阵 240 / 散 120 的代价与宽 22 带来的心理缓冲。
这一档把「突破是花费而非产出」这条基调推到最重（依据见总览 §4.1、§4.5），
也让玩家在最高境界的冲关里仍然只靠一次松手定生死。

## 5. 会在哪失手

- **松手落在区间外**：F「气机偏离」，散 120 枚灵石——代价最重的一档。
- **停在区间内但离正中 ±4 / ±8**：成功但只拿 A / B；宽 22 不等于好拿 S。
- **手抖或中途结束**：都算 F、都退一半；一次失手就丢 120 枚，容易让人不敢再冲。
- **长按等两个来回**：触控中断风险随按住时长上升（待验见 04-圆满.md §6）。
