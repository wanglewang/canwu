# 灵植·三秀连收诀 → 三秀同收（总）

> 在灵畦里互换相邻两株，凑齐三株同色即采收；新苗落下还能再连锁。换不出三连就少一息。
>
> 五段六篇：本篇放五段共用的骨架（盘面 / 规则 / 依据 / 界面 / 代码），
> 每段的花色、时辰、罚息与评级线写在各段文档里，两边不互相抄。
> 这一门是唯一「一张表管全」的玩法（`MATCH_LEVELS`），整表按段逐段展开到各段篇 §1。

- 功法：灵植·三秀连收诀（黄阶，offline +12%）｜玩法 id：`harvest`｜阶段新法：照畦 / 连收
- 时长基准 `base = 34`

**这组文档怎么读**：本文件只写「五段共用」的东西。每一段的整表行与手感各有一篇，数字都在那里：

| 段 | 关 | 关数 | 花色 | 时辰 | S 线 | 文档 |
| --- | --- | --- | --- | --- | --- | --- |
| 一 · 未入门 | 1–10 | 10 | 5 | 68 息 | ≥1900 | [未入门](00-未入门.md) |
| 二 · 入门 | 11–50 | 40 | 5 | 60 息 | ≥1750 | [入门](01-入门.md) |
| 三 · 小成 | 51–200 | 150 | 6 | 58 息 | ≥1400 | [小成](02-小成.md) |
| 四 · 大成 | 201–500 | 300 | 6 | 55 息 | ≥1300 | [大成](03-大成.md) |
| 五 · 圆满 | 501–1000 | 500 | 7 | 52 息 | ≥950 | [圆满](04-圆满.md) |

跨段看：花色 5→7、时辰 68→52 息、罚息 −1→−3。**S 线随盘面变难而降低（1900 → 950）**——
7 色盘上随机凑出三连的概率远低于 5 色，同样分数含金量不同。这条必须写进准备页与说明页，
否则玩家会以为算错了（见 §5）。

**只有一套关号。** 一门一条 1–1000 的线、五段，段位不是玩家挑的，只是「已走通几关」的另一个说法
（见 `10-systems/07-difficulty.md`）。关号由走通推进，一局只推一关，段位由 `cleared` 读。
本篇与小篇里的「第 501 关」就是玩家看见的那个关号。

## 1. 盘面骨架（五段共用）

6×6 = 36 格，铺满灵植。

- 花色数按段 5 → 7（`kinds`）；
- 每次采收后上方落下、顶上补新苗，盘面**永远是满的**；
- 图案用 `crest` sprite（八张牌，绝境用到第 7 张）；
- **没有可行换位时自动重排**，绝不把玩家卡在死局里。

## 2. 规则骨架（五段共用）

| 项 | 规则 |
| --- | --- |
| 采收 | 点相邻两株换位，使三株同色连成一线（横或竖 ≥3） |
| 无效互换 | 换不出三连 → 少 `missCost` 息 |
| 连锁 | 落下后再次凑成一线 → 连锁 +1 层，一层比一层值钱 |
| 重排 | 花 `shuffleCost` 息，把全盘重排 |
| 照畦（提示） | 花 `hintCost` 息，指出一步能三连的换位 |
| 结束 | 时辰到 |

**没有 F**：只看时限内的总分。

## 3. 五段怎么变

每一步只收紧一到两个数，符合「递增曲线平缓，无断崖」：

| 段 | 这一段新学的一件事 | 主轴 |
| --- | --- | --- |
| 一 · 未入门 | 找三连：相邻两株换位、横或竖 ≥3 即采收 | 复杂度（5 色） |
| 二 · 入门 | 无效互换要罚息，「想好了再换」成为必要 | 代价（罚息 −1 → −2） |
| 三 · 小成 | 多一色（5 → 6）：同色候选被压少，找三连更难 | 复杂度（花色） |
| 四 · 大成 | 罚息再收一档（−2 → −3）；解锁「照畦」少扣 1 息（仍要付） | 代价 + 便利 |
| 五 · 圆满 | 再多一色（6 → 7）：同色候选最少；解锁「连收」，S 线反降到 950 | 复杂度 + 收益 |

### 3.1 阶段新法（大成 / 大圆满）

| 段位 | 名 | 规则 | 可关 |
| --- | --- | --- | --- |
| 大成 | 照畦 | 「照畦」**少扣 1 息（仍要付）** | 否 |
| 大圆满 | 连收 | 连锁从第 3 层起额外加成；重排少扣 1 息 | 否 |

**这两条是原则第十一节的标准写法**：便利可以有，但必须有明码代价——「少扣 1 息」而不是「不扣」。
而且加成从第 3 层才给，得先打出连锁才拿得到，不是白送。
大成、圆满两段的具体体现分别见 [大成](03-大成.md) §2 / [圆满](04-圆满.md) §2。

## 4. 设计依据

### 4.1 为什么整表管理而不是公式缩放

旧版只有「S 线 620 + depth×150」在变，60 息 / 5 色 / 罚 2 息四段全写死。真控制器跑 12 局的结果：
高手五段 12/12 全 S、常人绝境 10/12 S——**等于同一局打五遍**。

现在每段只收紧一到两个数：

- 简单 → 普通：收时辰与罚息；
- 普通 → 困难：多一色；
- 困难 → 极难：收时辰与罚息；
- 极难 → 绝境：再多一色。

每一步都只动一两个数，符合「递增曲线平缓，无断崖」。

### 4.2 为什么 S 线要降

这是全站唯一「越难越低」的线。理由见 §1 表后的说明：花色越多，同样分数越难拿到。
落点目标是「高手 75–95% 拿得到、常人 5–25%」，由 `npm run audit:diff` 与 `tests/rank.test.js` 一起守。

如果按「越难越高」写，圆满段会变成「只有极少数人能拿 S」，而 S 的概率本该与段位大致相当。

### 4.3 为什么无效互换要罚息

不罚的话，玩家可以靠「狂换」试出三连——换位本身成了搜索工具。罚息让「想好了再换」成为必要。

### 4.4 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| S 线随段上升 | 见 §4.2 |
| 无效互换不罚 | 可以靠试（见 §4.3） |
| 死局不重排 | 卡死玩家 |
| 照畦免费 | 辅助必须有代价（原则第九条） |
| 「照畦不扣息」 | 原则第十一节：便利要有明码代价，改为「少扣 1 息」 |

## 5. 界面与反馈（五项逐门过）

原文 §6「界面」与 §6.5「界面与反馈」合列如下。

- 局内代价句按本段生成：「换不出三连少 N 息」（`tipFor()` 现拼，不写死）；
- 准备页难度栏显示本段花色 / 时辰 / 罚息 / S 线；
- 无效互换有轻震反馈，与连锁的中量震动区分开。

| 项 | 落点 |
| --- | --- |
| 难度 | 主承重轴是**复杂度**：花色 5→7、时辰 68→52 息、罚息 −1→−3。花色是真正的难点（7 色盘上凑三连的概率远低于 5 色），所以 S 线反而随段下降。 |
| 显示 | 准备页难度栏写清本段花色 / 时辰 / 罚息 / S 线；局内代价句按段现拼（`tipFor()`），不写死。 |
| 特效 | 无效互换轻震，补苗从上方压进来（下面两行表详说）。 |
| 引导 | goal 一句「换相邻两株凑三连」+ 三步 + 词条；首局有入门卡。 |
| 关卡 | 段内按 `duration` 与 `flashMs` 收紧；盘面固定 6×6，`levelDelta` 报时辰与亮起时长。**1000 关里 143 关真的变了**，其余据实写「与上一关规格相同」。 |

**v9 口径修正**：原文写「段内 40 关按 `duration` 与 `flashMs` 收紧」，其中「段内 40 关」是 v8 旧口径；
v9 五段关数为 10 / 40 / 150 / 300 / 500，段内收紧按 v9 关号段理解，「143 关真的变了」是原文实测值，照抄不改。

### 5.1 两种「刚才发生了什么」

| 情形 | 反馈 | 为什么 |
| --- | --- | --- |
| 换不出三连 | 两株各抖一下（横向 ±7rpx 三次回正） | 只少 2 息、不抖，玩家会以为「没点上」，接着再点一次 |
| 收走后补苗 | 新补的那几株从上方压进来（最多 8 格带 `cell--drop`） | 连锁是「落下来的新苗又凑成一线」，看不到落下，连锁就像凭空发生 |

两条都只动 `transform`：动效被系统「减少动效」关掉时，牌还在原位，只是不抖也不落。
类名带 `0/1` 交替序号——同名类连挂两帧不播动画，相邻两手才会各自重播一次。

**被否决的方案**

- **整盘连锁脉冲**（每层连锁给全盘加一层光）：连锁本来就带金浮字与粒子，再加整盘光
  是三层叠加，玩家只看到「屏幕在闪」。
- **给每一格补苗都挂落下动画**：一次连锁能补一二十格，全挂等于整盘乱抖。只画最上面八格，
  玩家视线本来就在落点附近。

以下为全门性待验；「绝境 7 色 52 息 S 线 950」那一条段相关，落在 [圆满](04-圆满.md) §6，本文件不重复。
