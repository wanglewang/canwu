# 合术·叠元诀 → 滑格相合

> 整行整列往一个方向挤，同数相撞就合成双倍；空出来的格子里再补一块新的。合出本档目标块就收功。

- 功法：合术·叠元诀（黄阶，power +5%）｜玩法 id：`heyuan`｜无阶段新法
- 时长基准 `base = 34`

## 1. 盘面

4×4 滑格。开局只有 2 块（高档 3–4 块），其余空着。

- 每块上是 2 的幂（2 / 4 / 8 / 16……）；
- 数字**直接显示**——这一门不换图案，读数是玩法核心；
- 四向操作，整行整列一起动。

## 2. 规则

| 项 | 规则 |
| --- | --- |
| 合并 | 同一行/列往一个方向挤，同数相撞合成双倍 |
| 补块 | 每次操作后，空格中随机补一块新的 |
| 收功 | 合出**本档目标块**即收功 |
| 走火（F） | 盘满且相邻无同数、再也推不动 |
| 得分 | 合并值累加，**只用于破纪录**，不参与评级 |

**评级只看「最大那一块合到多大」**，不看总分。

## 3. 操作

**在盘面上四向滑动**：往哪划，整盘就往哪挤（`vm.extras.swipeMove`，页面挂一层透明滑动层）。
不摆方向键——拇指本来就盖在盘上，再挪到底部去按四个箭头，等于每走一步换一次手。

判据只看起点到终点的位移（24px 起步，斜划取主轴），不跟轨迹：推盘是一步决策，不是画线。

## 4. 五档参数

| 档 | 目标 | 起手块 | S | A | B | C |
| --- | --- | --- | --- | --- | --- | --- |
| 简单 | 128 | 2 | 合出 128 | 64 | 32 | 没到 32 |
| 普通 | 256 | 2 | 合出 256 | 128 | 64 | 没到 64 |
| 困难 | 256 | 3 | 合出 256 | 128 | 64 | 没到 64 |
| 极难 | 512 | 3 | 合出 512 | 256 | 128 | 没到 128 |
| 绝境 | 1024 | 4 | 合出 1024 | 512 | 256 | 没到 256 |

**盘面五档不变（4×4）**。变的是目标块、起手块数，以及「起手给 4 的概率」：

- `fourRate` 从 0.45 一路收到 0.20（跟着关卡走），白送的 4 越少，凑同数就得自己多推几步；
- 这一条是章内**唯一**的连续量：目标块只能一档一档翻倍，光靠它做不到「每五关一个小变化」。

- 目标更高 → 需要更多步；
- 起手块更多 → 开局可用空间更少，更容易被堵死。

这两个数是区分度审计补上的第二个参数：原本只有目标在变，玩家感受不到困难与极难的区别。

## 5. 评级

**S = 达成目标**，A/B/C 依次递减。这叫「达成制」而不是「分数制」：

- 达成目标即收功，所以 S 是「完成本档任务」；
- 没达成但合到了 A 线，说明「差一点」；
- 盘满推不动 → F（无路可走，不是「打得糙」）。

## 6. 设计依据

### 与三秀同收、落石垒基的分工

| | 三秀同收 | 落石垒基 | 滑格相合 |
| --- | --- | --- | --- |
| 格子 | 换相邻两格 | 块自己落 | 整行整列挤 |
| 消除 | 三连 | 填满整层 | 同数翻倍 |
| 节奏 | 限时 | 实时下落 | 回合制（无时限压力） |
| 结束 | 时辰到 | 时辰到 / 堆顶 | 合出目标 / 盘满 |

三者都是「格子类」，但动作完全不同：换、落、挤。

### 为什么不用时限

这一门没有时间压力——压力来自「盘满堵死」。加时限会变成「手速游戏」，而它本该是「规划游戏」。

**这也是全站唯一一个「只靠失败条件而不靠时限」的玩法**。

### 为什么起手块数也算难度

起手 2 块与 4 块在 4×4 上的差别极大：4 块时几乎一半空间已被占，前几步的可选路径少很多。用它作为「第二难度旋钮」比再抬目标更有效——抬目标只是更长的重复，加起手块是真的变紧。

### 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 按总分评级 | 总分可以靠「小合并多得」堆，与「合出大块」的技术含量不符 |
| 加时限 | 见上 |
| 目标只靠抬数值 | 会变成更长的重复，不是更难 |
| 盘面放大到 5×5 | wxss 只有 `.grid--c3/4/6`，且 5×5 会让目标块需求暴涨 |
| 用图案代替数字 | 读数就是玩法，换图案等于换玩法 |

## 8. 待验

- 4×4 在 4.7 寸屏的滑动方向误判（四向滑动容易识别成斜向）。
- 起手 4 块（绝境）是否会让开局就很紧张、甚至「几步内必堵」。
- 目标 1024 一局要多久：没有时限，玩家可能打十几分钟，与「碎片时间」定位有冲突。
- 「达成即收功」是否会让玩家觉得「刚热身就结束了」——A/B/C 档尤其明显。
