## 1. 盘面骨架（五段共用）

一局开始时生成一道**刀路**：从 3 到 8 个桩按序连成，最后一格是靶心。盘面 3×3 至 5×5（9 至 25 格，按段变，见 `data/practice.js` 的 `CLICK_LEVELS`）。

- 每桩画一个 CSS 箭头，指下一桩；
- 刀光按序点亮，走到哪一桩，那一桩实心起光；
- 靶心是收势点，不指出去；
- 盘面**不写汉字**，方向全靠箭头。

盘面大了一件事要说清：4×4 与 5×5 上「直线刀路」越来越难找，绝大多数刀路必然是折线。这不是副作用，正是这一门要练的东西——**顺着光判断下一个拐点在哪**。

## 2. 规则骨架（五段共用）

| 项 | 规则 |
| --- | --- |
| 斩中 | 手指从第一桩沿箭头划到靶心，中间不跳桩 |
| 劈空 | 反向划、跳桩、绕一大圈 → 扣 1 息、刀势清零 |
| 漏 | 刀光寿命走完还没划中 → 断刀势（不罚息） |
| 重斩 | 每第 5 道（后段更密）：刀路更长、分翻倍、寿命八折；**漏了不断刀势** |
| 连击 | 连中 5 / 10 / 20 记后，单刀得分 ×1.5 / ×2 / ×3；一次失误退回 ×1 |

**两种失误的代价不同**：

- 「明知道该怎么划却乱划」→ 罚息（劈空）；
- 「规则内的看错」（碰到禁桩、划到虚影、收势没停住）→ 只断刀势，不罚息。

分界线是「**是否违招**」：反向、跳桩、绕圈是「不按刀法走」，罚息；碰到禁桩、收势没停住是「按刀法走但看错了」，只断势。前者是态度问题，后者是水平问题。

**操作**：滑动（`swipe`）。手指沿线经过桩的判定圈即算命中，抬指在靶心才算收势。
页面挂一层 `swipe-layer` 接住手势——**这是全站唯一用滑动的玩法**，也是真机上最需要复核的一门。

### 2.1 阶段新法（三条都是「改规则」）

| 段位 | 名 | 规则 | 可关 |
| --- | --- | --- | --- |
| 大成 | 收势 | 扫到靶心要**停一拍**再抬手；抢着抬算收势未成，只给半分并断刀势 | 是 |
| 圆满 | 禁桩 | 盘上多出红叉禁桩，划到即断刀势；绕开它把刀路走完才算数 | 是 |

## 4. 设计依据

### 4.1 为什么从「点」改成「划」

早期版本是「点桩」：点亮哪一桩点哪一桩。问题有两个：

1. **点桩没有「一刀」的意象**。刀法是连贯的，点按是离散的；
2. **连点可以无脑加速**，玩家会用最快速度点完一串，而没有「顺着力走」的感觉。

改成滑动之后，玩家的手指要**沿路径移动**，动作本身就表达了「一刀掠过」。代价是滑动在真机上有手感风险（系统手势、插值补全的命中率），所以这一门是全站真机复核优先级最高的一门。

### 4.2 为什么劈空罚息、规则内失误只断势

如果所有失误都罚息，玩家会变得不敢动；如果所有失误都不罚，乱划就能试出答案。
分界线是「是否违招」（见 §2）：罚息治态度，断势治水平。

### 4.3 为什么承重轴是复杂度，不是速度

这个配比是刻意的：**反应速度练不出来**。把难度压在「快」上，玩家练十局只是眼睛更累，输了也说不出该练什么；更长的刀路练的是记路与预判，输了能明确说「那一段拐点我没记住」。

旧版正好反过来——盘面恒 3×3、刀路封顶 5 桩，而光速跨度 2.86 倍（343→120），难度几乎全在「快」上。这一版把光速跨度收到 2.17 倍，多出来的难度交给盘面与刀路。

### 4.4 为什么刀法的阶段新法全是「改规则」而其他九门只给便利

刀法是初始三门的第一门，玩家最先练到高段位的就是它。若它到圆满还是「同一件事快一点」，那「阶段新法」这个概念在第一门功法上就等于不存在。

### 4.5 被否决的方案

| 方案 | 为什么否掉 |
| --- | --- |
| 点桩（旧版） | 见 §4.1 |
| 全用 canvas 画刀光 | 格子按序点亮 + 一道 CSS 白光扫过就能表达，canvas 会带来坐标系与真机性能问题 |
| 重斩漏了也罚 | 重斩是「加菜」，漏了罚会让人不敢接 |
| 连击门槛固定 5/10/20 | 后段应更密（更难连），现在按 `depth` 收紧 |
| 无寿命线（刀光一直等） | 没有「漏」的代价，玩家可以慢慢找路径，刀法就变成了连线题 |

## 5. 界面与反馈

原文没有独立的「界面与反馈」节，按五项逐门过（数字均来自原文）：

1. **判据**：这一刀顺箭头划到靶心即斩中；盘上刀光按序点亮、当前桩实心起光；连中 5/10/20 记后单刀 ×1.5/×2/×3。
2. **代价**：劈空扣 1 息、刀势清零；「规则内看错」（碰禁桩 / 划到虚影 / 收势没停住）只断刀势不罚息；重斩漏了不断刀势。
3. **操作**：`swipe` 滑动，沿线经桩判定圈命中，抬指在靶心才收势；`swipe-layer` 接手势。
4. **进度**：原文未给 HUD 进度的具体数字，只给时辰（15→13 秒，段篇展开）与连击记数（5/10/20）——不补写原文没有的读数。
5. **收束**：时间到即本局终点；**没有 F**（四门「只看产出」的玩法之一），时间到不是失手。

评级按本局总得分，五段的 S/A/B 线见 §6 与对应段篇 §3。S 线随段上升——与三秀同收相反：刀法得分主要由「命中数 × 连击倍率」决定，难度越高盘面给的刀数越多（节奏更快），理论上限反而更高。其余为 C。
